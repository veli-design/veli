## Create a project

Use Node.js 24 or newer.

```bash
npm create astro@latest my-veli-app
cd my-veli-app
npx astro add react
npm install tailwindcss @tailwindcss/vite
```

## Install packages

Install the shared packages from [Installation](/getting-started/installation/).

```bash setup=install
npm install @veli-design/react @veli-design/tokens react-aria-components
```

## Add styles

Register the Tailwind Vite plugin. Keep the React integration.

```js
import { defineConfig } from 'astro/config';
import react from '@astrojs/react';
import tailwindcss from '@tailwindcss/vite';

export default defineConfig({
  integrations: [react()],
  vite: {
    plugins: [tailwindcss()],
  },
});
```

Create `src/styles/global.css`.

```css setup=css-imports
@import 'tailwindcss';
@import '@veli-design/tokens/tailwind';
@import '@veli-design/react/tailwind';
```

Import that file from the shared layout.

## Add the provider

Set the document class before first paint. Put this script in the layout `head`. It writes `.dark`, `data-theme`, and `color-scheme` on `document.documentElement`.

```astro
---
import '../styles/global.css';
---

<!doctype html>
<html lang="en" data-color-scheme="system">
  <head>
    <script is:inline>
      (() => {
        const storageKey = 'veli-color-scheme';
        const root = document.documentElement;
        const stored = window.localStorage.getItem(storageKey);
        const colorScheme =
          stored === 'light' || stored === 'dark' || stored === 'system' ? stored : 'system';
        const isDark =
          colorScheme === 'dark' ||
          (colorScheme === 'system' && window.matchMedia('(prefers-color-scheme: dark)').matches);
        const resolvedColorScheme = isDark ? 'dark' : 'light';

        root.classList.toggle('dark', isDark);
        root.dataset.theme = resolvedColorScheme;
        root.dataset.colorScheme = colorScheme;
        root.style.colorScheme = resolvedColorScheme;
      })();
    </script>
  </head>
  <body class="bg-surface-base text-base">
    <slot />
  </body>
</html>
```

Veli components are React client components. Astro renders them as static HTML unless you set a client directive. Hydrate each interactive component when the page loads. The sample below shows the directive.

```astro
---
import { Button } from '@veli-design/react/button';
---

<Button client:load>Save</Button>
```

Wrap island state that needs language or color-scheme context in `VeliProvider`. The layout script owns the document class. The provider owns the React subtree.

```tsx
import { VeliProvider } from '@veli-design/react/provider';

export function Island({ children }: { children: React.ReactNode }) {
  return (
    <VeliProvider language="en" colorScheme="system">
      {children}
    </VeliProvider>
  );
}
```

Theme buttons elsewhere on the page should write the same root contract and save `veli-color-scheme` to `localStorage`.

## Connect the router

Astro moves between pages with normal links. Leave `navigate` unset. Set it only inside a React island that uses a client router. The [React Router](/getting-started/react-router/) guide shows that wiring.

## Load fonts

Import the font stylesheet from the layout, next to `global.css`. [Fonts](/getting-started/fonts/) has the family rules and the Dhivehi token names.

## Verify

```bash
npm run dev
```

The button shows Veli styles and responds to a click. Without the load directive, the button paints and the click does nothing. Toggle the saved color scheme. The document element gains the class `dark` before the first paint, with no flash of the opposite theme.
