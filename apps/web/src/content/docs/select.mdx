# Select

<DocsTab id="overview">

A select lets people choose one value from a short, known list, such as an atoll or a document type. Use it when the options are fixed and people should not type their own. The chosen value shows in a trigger button, and the options open in a list below it.

  source="https://github.com/veli-design/veli/blob/main/packages/react/src/select.tsx"
  storybook="https://storybook.veli.design/?path=/docs/components-select--docs"

## When to use

### Use a select when

- People must choose one value from a known set of options, such as an atoll or a document type.
- The options are fixed and people should not type their own.
- There are too many options to show as radio buttons.
- The options benefit from descriptions, leading or trailing content, or grouped sections.

### Don't use a select when

- The list is long and people would rather search or type into it. Use Combobox.
- A small set of choices should stay visible for comparison. Use Radio button.
- People can choose more than one option. Use Checkbox.
- The list runs actions rather than setting a value. Use Menu.

<DocsAnatomy>

1. **Label**

   Names the field. In code: label.

2. **Info icon**

   A 16 x 16 button that opens a tooltip with more help. Optional. In code: infoTooltip.

3. **Optional**

   The localised word Optional after the label, shown with isOptional. When the field is required, an asterisk shows instead.

4. **Trigger**

   The button that opens the list. It is 36, 44 or 52 high and shows the placeholder or the selected value. In code: appearance and size.

5. **Caret**

   A 20 x 20 caret at every size. It turns up while the list is open. You can replace it with indicator.

6. **List**

   Opens 4 below the trigger and is as wide as it. It scrolls past 280.

7. **Section title**

   Groups options. Only in grouped lists. In code: SelectSection title.

8. **Option**

   One choice, at least 36 high, with an optional line of description. In code: SelectItem.

9. **Check**

   Marks the selected option, at the end of the row.

</DocsAnatomy>

Helper text, or the error message when the field is invalid, sits below the trigger.

## Content guidelines

### Label

Name the value, not the action. Use sentence case and no colon.

| Do            | Don't                                                       |
| :------------ | :---------------------------------------------------------- |
| Atoll         | Choose your atoll: (names the action and ends with a colon) |
| Type of home  |                                                             |
| Document type |                                                             |

### Placeholder

Use a short prompt on the empty choice, and keep the label above it: the placeholder goes once people choose. Always pass a placeholder, in both languages. Without one, the trigger shows the default text Select an item, which says Select rather than Choose and stays in English on Dhivehi pages.

| Do                     | Don't                                                         |
| :--------------------- | :------------------------------------------------------------ |
| Choose an atoll        | Select an item (the default text, in English even in Dhivehi) |
| Choose a document type |                                                               |

### Options

Write options as short, parallel phrases that do not overlap, in sentence case. Order them alphabetically, by size or by how often people choose them. Add None or I do not know when it is a valid answer.

| Do                                  | Don't                                                           |
| :---------------------------------- | :-------------------------------------------------------------- |
| Flat, House, Room in a shared house | I live in a FLAT (not parallel, and uses capitals for emphasis) |

### Helper text

Say what the list holds or how to choose, in one sentence with no full stop. Don't put links in helper text, labels or error messages.

| Do                                            | Don't                                                                  |
| :-------------------------------------------- | :--------------------------------------------------------------------- |
| The atoll where you live now                  | The atoll where you live now. (a one-sentence hint takes no full stop) |
| The document you will upload in the next step | Choose an option from the list (repeats what the select does)          |

### Error message

Say what to choose, in one sentence with no full stop. Start with Choose when an answer is missing.

| Do                           | Don't                                                                   |
| :--------------------------- | :---------------------------------------------------------------------- |
| Choose the atoll you live in | Invalid selection (does not say what to do)                             |
| Choose a type of home        | Choose the atoll you live in. (a one-sentence error takes no full stop) |

### Optional and required

Mark whichever is rarer in the form: Optional on optional fields when most are required, or the asterisk on required fields when most are optional. Never mark one field both ways. Optional is hidden when the field is required.

### Long text

Truncate only non-essential text in repeated items, when the full text shows elsewhere. The ellipsis sits at the inline end, which is the left in Dhivehi.

### Built-in strings and Dhivehi

Select has two built-in strings in English and Dhivehi: Optional, which you cannot reword, and the info button name More information (އިތުރު މަޢުލޫމާތު). Set infoTooltipAriaLabel so the info button names its topic. Two strings stay in English on Dhivehi pages: the default placeholder Select an item, which you replace with placeholder, and the hidden Dismiss buttons in the open list, which have no prop.

Write Dhivehi labels, placeholders, options, helper text and errors natively rather than translating word for word, and keep them as short as the English.

Select has no read-only state in code. When a chosen value must stay visible but locked, show the option label in a read-only Input and submit the option id separately. Don't use a disabled select instead: it reads as unavailable and is left out of form submission.

Select has no skeleton state in code. Compose Skeleton while the form data loads.

## Behaviour

- **Opening**: pressing the trigger opens the list 4 below it, as wide as the trigger.
- **Choosing**: choosing an option closes the list and shows the option in the trigger. It only sets the value: let people continue with a separate button, and never navigate or submit on change. Control the value with value and onChange, or set a starting value with defaultValue.
- **Typing on the closed trigger**: typing letters while the trigger has focus changes the value to a matching option without opening the list, like a native select.
- **Long lists**: the list scrolls past 280. For long or searchable lists, use Combobox.
- **Disabled**: set isDisabled to stop the list opening and remove the field from the tab order. Use disabledKeys to disable single options.
- **Validation**: set isInvalid to show errorMessage below in place of the description. Use isRequired and validate to check the value on submit.
- **Forms**: with React Hook Form, pass ref as triggerRef so the trigger can take focus on an error.
- **Fixed structure**: select is not editable or filterable. It takes no style or child layout overrides; className is for outer layout only.

## Usage

```tsx
<Select label="Country" isOptional placeholder="Choose a country" description="Helper text">
  <SelectItem id="my">Malaysia</SelectItem>
  <SelectItem id="sg">Singapore</SelectItem>
  <SelectItem id="th">Thailand</SelectItem>
```

## Locked value

Select has no `isReadOnly`. When a chosen option must stay visible but locked, show the option label in a read-only [Input](/docs/components/input/) and submit the option id separately. Leave `name` off the Input so the label is not the form payload. A disabled Select is the wrong stand-in: it reads as unavailable and is omitted from native form submission.

```tsx
import { Input } from '@veli-design/react/input';

const atoll = { id: '26', name: 'Kaafu Atoll' };

<>
  <Input label="Atoll" value={atoll.name} isReadOnly />
  <input type="hidden" name="atollId" value={atoll.id} />
</>;
```

If the form is fully controlled and never reads native `FormData`, keep `atoll.id` in application state and use the Input only for display.

## API Reference

Select is a Veli field on React Aria [`Select`](https://react-spectrum.adobe.com/react-aria/Select.html), composed with `Button`, `Popover`, and `ListBox`. Props below follow that stack.

### Select

Veli-specific props for the composed field.

| Prop                    | Type                          | Default            | Description                                                          |
| :---------------------- | :---------------------------- | :----------------- | :------------------------------------------------------------------- |
| `appearance`            | `'default' \| 'outline'`      | `'default'`        | Underline or bordered trigger.                                       |
| `size`                  | `'sm' \| 'md' \| 'lg'`        | `'md'`             | Field size.                                                          |
| `label`                 | `ReactNode`                   | -                  | Visible label.                                                       |
| `isOptional`            | `boolean`                     | `false`            | Shows localized Optional beside the label. Hidden when `isRequired`. |
| `infoTooltip`           | `ReactNode`                   | -                  | Content for the header info tooltip.                                 |
| `infoTooltipAriaLabel`  | `string`                      | Localized string   | Accessible name for the info tooltip trigger.                        |
| `labelIcon`             | `ReactNode`                   | -                  | Small icon after the label.                                          |
| `action`                | `ReactNode`                   | -                  | Trailing header content, such as an inline link.                     |
| `description`           | `ReactNode`                   | -                  | Helper text beneath the field.                                       |
| `errorMessage`          | `ReactNode`                   | -                  | Error text shown when `isInvalid`.                                   |
| `showRequiredIndicator` | `boolean`                     | `true`             | Shows the required asterisk when `isRequired`.                       |
| `startContent`          | `ReactNode`                   | -                  | Leading content inside the trigger.                                  |
| `endContent`            | `ReactNode`                   | -                  | Trailing content before the indicator.                               |
| `indicator`             | `ReactNode`                   | Caret              | Replaces the caret.                                                  |
| `placeholder`           | `string`                      | React Aria default | Text shown when nothing is selected.                                 |
| `value`                 | `K \| null`                   | -                  | Controlled selected key.                                             |
| `defaultValue`          | `K \| null`                   | -                  | Uncontrolled initial key.                                            |
| `onChange`              | `(value: K \| null) => void`  | -                  | Called with the selected key.                                        |
| `items`                 | `Iterable<T>`                 | -                  | Items for a dynamic collection.                                      |
| `children`              | `ReactNode \| (item: T) => …` | -                  | Options, or a render function for `items`.                           |
| `triggerRef`            | `Ref<HTMLButtonElement>`      | -                  | Ref to the trigger, for focusing it on form errors.                  |
| `className`             | `string`                      | -                  | Layout class on the root (width, margin, flex/grid).                 |

### React Aria Select

React Aria’s headless [`Select`](https://react-spectrum.adobe.com/react-aria/Select.html#props). These props pass through. The React Aria docs cover the rest, except the exclusions below.

| Prop           | Type                        | Default | Description                              |
| :------------- | :-------------------------- | :------ | :--------------------------------------- |
| `isDisabled`   | `boolean`                   | `false` | Disables the field.                      |
| `isInvalid`    | `boolean`                   | `false` | Marks the field invalid.                 |
| `isRequired`   | `boolean`                   | `false` | Marks the field required.                |
| `disabledKeys` | `Iterable<Key>`             | -       | Keys of options to disable.              |
| `name`         | `string`                    | -       | Native form field name.                  |
| `validate`     | `function`                  | -       | Custom validation.                       |
| `isOpen`       | `boolean`                   | -       | Controlled open state.                   |
| `onOpenChange` | `(isOpen: boolean) => void` | -       | Called when the listbox opens or closes. |
| `autoFocus`    | `boolean`                   | `false` | Focuses the trigger on mount.            |

Not forwarded from React Aria `Select`:

| Prop                                | Why                                                                    |
| :---------------------------------- | :--------------------------------------------------------------------- |
| `children`, `items`                 | Replaced by Veli’s option `children` and `items` above.                |
| `value`, `defaultValue`, `onChange` | Replaced by Veli’s typed key props above.                              |
| `style`                             | Not supported.                                                         |
| `className`                         | Replaced by Veli’s layout `className` on the root.                     |
| `isReadOnly`                        | Not supported by React Aria Select. See [Locked value](#locked-value). |

## Accessibility

- Give the field a visible `label`, or pass `aria-label` / `aria-labelledby` when the label is hidden.
- The trigger announces its label and selected value. Space, Enter, and the arrow keys open the listbox, and typing jumps to a matching option.
- `description` is the accessible helper. On error, `errorMessage` replaces it.
- Give icon-only or composed options a `textValue` or `aria-label`.

## RTL and Language

On `lang="dv"` pages, the trigger value, options, and section headers use `MV_Faseyha` in both the field and the popover. In RTL, the trigger content, caret, option content, and selected check follow `dir`.

How the select works with keyboards, screen readers and assistive settings. The trigger is a button that opens a listbox, built on React Aria Select.

## Keyboard

| Key                                  | Action                                                               |
| :----------------------------------- | :------------------------------------------------------------------- |
| Tab                                  | Moves focus to the trigger, and on to the next control               |
| Enter, Space, Up arrow or Down arrow | Opens the list on the trigger                                        |
| Up arrow and Down arrow              | Move between options in the open list, including across sections     |
| Enter                                | Chooses the focused option and closes the list                       |
| Escape                               | Closes the list without changing the value                           |
| Letters                              | Jump to a matching option, in the open list or on the closed trigger |

## Screen readers

- The trigger is a button that announces the label and the chosen value, and reports that it opens a listbox and whether it is open. This differs from the select-only combobox pattern on purpose.
- The open list is a listbox labelled by the field label. Each option is an option that reports whether it is selected.
- The description and the error message are announced with the field, so people hear the help and the error.
- Optional and the required asterisk sit outside the label, so neither is part of the accessible name. isRequired still tells screen readers the field is required.
- Give options with rich content, such as an icon or a description, a textValue or aria-label so typeahead, the selected value and screen readers have plain text.
- A hidden native select carries the value for autofill and form submission. Automated checkers can flag it as an aria-hidden element with focusable content; this is a known false positive.

## Labels

Give every select a visible label. Use aria-label or aria-labelledby only when the design has no visible label. The label names the trigger. A tooltip must not be the only source of the name.

## Focus

- Keyboard focus shows a 2px ring in `border/focus` with a 2px offset around the field. It appears for keyboard focus only. A click opens the list and shows the active state instead.
- With the ring, the outline appearance drops its border, so the two never stack.
- In the open list, the focused option shows the `menu/hover` background. Options have no ring of their own.

## Selected state

The selected option shows a check mark, a shape that survives forced colours, not colour alone.

## List roles

Select options look like menu items but keep the listbox and option roles. Never rebuild a select list from Menu or MenuItem. Don't put buttons, links or checkboxes inside an option: an option holds text, with an optional description, icon and end content that is not interactive.

## Disabled

A disabled select cannot open and is removed from the tab order. Disabled options stay visible but cannot be chosen. Disabled text is exempt from contrast minimums, so don't put information people need only in a disabled field.

## Target size

Every trigger size (36, 44 and 52 high) meets the 24 x 24 minimum target size, and options are at least 36 high. 44 is the recommended size for touch: md and lg reach it, so use sm only in dense layouts. The info button is 16 x 16, below the 24 x 24 minimum, and is a known failure.

## Contrast

Errors show a message as well as the red line. Placeholder text uses `text/base/inactive`, which does not meet 4.5:1, and Optional is about 3.0:1, so keep key information out of the placeholder and Optional.

## Zoom and phones

- Keep the open list inside the viewport at high zoom.
- Text in a field should be at least 16 on phones so iOS Safari does not zoom the page. Select text is 14 at sm and md and 16 at lg, so use lg on phones.
- Use the lg select on kiosk screens; it also meets the 44 kiosk target.

## Right to left

Set the language with VeliProvider (language dv). It sets the direction and the language, so screen readers can switch to a Dhivehi voice. The trigger content, caret, options and check mirror. Pass Dhivehi labels, placeholders and options yourself. The hidden Dismiss buttons in the open list stay in English.
