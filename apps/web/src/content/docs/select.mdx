# Select

Use Select to choose one value from a short, known list. For long or searchable lists, use [ComboBox](/docs/combobox/). For actions instead of values, use [Menu](/docs/menu/).

## Import

```tsx
import { Select, SelectItem, SelectSection } from '@tradenetcorp/veli-ui/select';
```

## Usage

<div className="preview mb-4 rounded-lg border p-4">
  <SelectUsageDemo client:visible />
</div>

```tsx
<Select label="Country" isOptional placeholder="Choose a country" description="Helper text">
  <SelectItem id="my">Malaysia</SelectItem>
  <SelectItem id="sg">Singapore</SelectItem>
  <SelectItem id="th">Thailand</SelectItem>
</Select>
```

Control the selection with `value` and `onChange`. With React Hook Form, pass `ref` as `triggerRef`. See [Forms](/patterns/forms/) for recipes.

## Appearances

`default` uses the underline trigger. `outline` draws a bordered trigger. Size the field with `sm`, `md`, or `lg`.

<div className="preview mb-4 rounded-lg border p-4">
  <SelectAppearancesDemo client:visible />
</div>

```tsx
<Select label="Default" placeholder="Choose an option">…</Select>
<Select appearance="outline" label="Outline" placeholder="Choose an option">…</Select>
```

## Sections

Group options with `SelectSection`. Options can carry a `description` and leading `startContent`.

<div className="preview mb-4 rounded-lg border p-4">
  <SelectSectionsDemo client:visible />
</div>

```tsx
<Select label="Island" placeholder="Choose an island">
  <SelectSection title="Popular">
    <SelectItem id="male" description="Capital city">
      Male'
    </SelectItem>
    <SelectItem id="hulhumale" description="Reclaimed island">
      Hulhumale'
    </SelectItem>
  </SelectSection>
  <SelectSection title="Regional">
    <SelectItem id="addu">Addu City</SelectItem>
    <SelectItem id="fuvahmulah" isDisabled>
      Fuvahmulah City
    </SelectItem>
  </SelectSection>
</Select>
```

## Validation

When `isInvalid` is set, `errorMessage` replaces the helper text.

<div className="preview mb-4 rounded-lg border p-4">
  <SelectValidationDemo client:visible />
</div>

```tsx
<Select label="Status" isInvalid errorMessage="Choose a status to continue.">
  <SelectItem id="active">Active</SelectItem>
  <SelectItem id="inactive">Inactive</SelectItem>
</Select>
```

## API Reference

Select is a Veli field on React Aria [`Select`](https://react-spectrum.adobe.com/react-aria/Select.html), composed with `Button`, `Popover`, and `ListBox`. Props below follow that stack.

### Select

Veli-specific props for the composed field.

| Prop                    | Type                          | Default            | Description                                                          |
| :---------------------- | :---------------------------- | :----------------- | :------------------------------------------------------------------- |
| `appearance`            | `'default' \| 'outline'`      | `'default'`        | Underline or bordered trigger.                                       |
| `size`                  | `'sm' \| 'md' \| 'lg'`        | `'md'`             | Field size.                                                          |
| `label`                 | `ReactNode`                   | -                  | Visible label.                                                       |
| `isOptional`            | `boolean`                     | `false`            | Shows localized Optional beside the label. Hidden when `isRequired`. |
| `infoTooltip`           | `ReactNode`                   | -                  | Content for the header info tooltip.                                 |
| `infoTooltipAriaLabel`  | `string`                      | Localized string   | Accessible name for the info tooltip trigger.                        |
| `labelIcon`             | `ReactNode`                   | -                  | Small icon after the label.                                          |
| `action`                | `ReactNode`                   | -                  | Trailing header content, such as an inline link.                     |
| `description`           | `ReactNode`                   | -                  | Helper text beneath the field.                                       |
| `errorMessage`          | `ReactNode`                   | -                  | Error text shown when `isInvalid`.                                   |
| `showRequiredIndicator` | `boolean`                     | `true`             | Shows the required asterisk when `isRequired`.                       |
| `startContent`          | `ReactNode`                   | -                  | Leading content inside the trigger.                                  |
| `endContent`            | `ReactNode`                   | -                  | Trailing content before the indicator.                               |
| `indicator`             | `ReactNode`                   | Caret              | Replaces the caret.                                                  |
| `placeholder`           | `string`                      | React Aria default | Text shown when nothing is selected.                                 |
| `value`                 | `K \| null`                   | -                  | Controlled selected key.                                             |
| `defaultValue`          | `K \| null`                   | -                  | Uncontrolled initial key.                                            |
| `onChange`              | `(value: K \| null) => void`  | -                  | Called with the selected key.                                        |
| `items`                 | `Iterable<T>`                 | -                  | Items for a dynamic collection.                                      |
| `children`              | `ReactNode \| (item: T) => …` | -                  | Options, or a render function for `items`.                           |
| `triggerRef`            | `Ref<HTMLButtonElement>`      | -                  | Ref to the trigger, for focusing it on form errors.                  |
| `className`             | `string`                      | -                  | Layout class on the root (width, margin, flex/grid).                 |

### React Aria Select

React Aria’s headless [`Select`](https://react-spectrum.adobe.com/react-aria/Select.html#props). These props pass through. The React Aria docs cover the rest, except the exclusions below.

| Prop           | Type                        | Default | Description                              |
| :------------- | :-------------------------- | :------ | :--------------------------------------- |
| `isDisabled`   | `boolean`                   | `false` | Disables the field.                      |
| `isInvalid`    | `boolean`                   | `false` | Marks the field invalid.                 |
| `isRequired`   | `boolean`                   | `false` | Marks the field required.                |
| `disabledKeys` | `Iterable<Key>`             | -       | Keys of options to disable.              |
| `name`         | `string`                    | -       | Native form field name.                  |
| `validate`     | `function`                  | -       | Custom validation.                       |
| `isOpen`       | `boolean`                   | -       | Controlled open state.                   |
| `onOpenChange` | `(isOpen: boolean) => void` | -       | Called when the listbox opens or closes. |
| `autoFocus`    | `boolean`                   | `false` | Focuses the trigger on mount.            |

Not forwarded from React Aria `Select`:

| Prop                                | Why                                                        |
| :---------------------------------- | :--------------------------------------------------------- |
| `children`, `items`                 | Replaced by Veli’s option `children` and `items` above.    |
| `value`, `defaultValue`, `onChange` | Replaced by Veli’s typed key props above.                  |
| `style`                             | Not supported.                                             |
| `className`                         | Replaced by Veli’s layout `className` on the root.         |
| `isReadOnly`                        | Not supported by React Aria Select. Use a read-only Input. |

### SelectItem

| Prop           | Type        | Default | Description                                                 |
| :------------- | :---------- | :------ | :---------------------------------------------------------- |
| `id`           | `Key`       | -       | Option key used by `value` and `onChange`.                  |
| `children`     | `ReactNode` | -       | Option label.                                               |
| `description`  | `ReactNode` | -       | Secondary text below the label.                             |
| `startContent` | `ReactNode` | -       | Leading content, such as an icon.                           |
| `endContent`   | `ReactNode` | -       | Trailing content before the selected check.                 |
| `textValue`    | `string`    | -       | Plain text for typeahead when `children` is not plain text. |
| `isDisabled`   | `boolean`   | `false` | Shows the option but blocks selection.                      |
| `className`    | `string`    | -       | Class merged onto the option.                               |

Other React Aria [`ListBoxItem`](https://react-spectrum.adobe.com/react-aria/ListBox.html#listboxitem) props pass through.

### SelectSection

| Prop        | Type        | Default | Description                    |
| :---------- | :---------- | :------ | :----------------------------- |
| `title`     | `ReactNode` | -       | Section header.                |
| `children`  | `ReactNode` | -       | The section’s options.         |
| `className` | `string`    | -       | Class merged onto the section. |

## Accessibility

- Give the field a visible `label`, or pass `aria-label` / `aria-labelledby` when the label is hidden.
- The trigger announces its label and selected value. Space, Enter, and the arrow keys open the listbox, and typing jumps to a matching option.
- `description` is the accessible helper. On error, `errorMessage` replaces it.
- Give icon-only or composed options a `textValue` or `aria-label`.

## RTL and Language

On `lang="dv"` pages, the trigger value, options, and section headers use `MV_Faseyha` in both the field and the popover. In RTL, the trigger content, caret, option content, and selected check follow `dir`.
