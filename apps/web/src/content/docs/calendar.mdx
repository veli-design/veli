# Calendar

<DocsTab id="overview">

Calendar shows one month as a grid of days on the page, with no field, for picking one date. RangeCalendar picks a start and an end date. Use a calendar where people browse dates, such as checking which appointment days are open.

## When to use

### Use a calendar when

- You embed date selection directly in a scheduling, booking, filter or availability surface.
- People need to see constrained or unavailable dates in the context of the month.
- The selected or focused date must stay in sync with other controls on the page. Use a controlled calendar.
- People choose a start and an end date. Use RangeCalendar.

### Don't use a calendar when

- Date selection should stay compact until people open it. Use a date picker.
- People only need to type a date. Use a date field.
- The date is one people know by heart, such as a date of birth. Prefill it from the National Registry through eFaas. Otherwise use a date field in English. In Dhivehi, use three Inputs with bday autocomplete: under dv the Date field segments read month, day, year from the right (mm / dd / yyyy), which differs from the guidelines, and the segment names stay in English.
- It would be the only way to enter a date in a form, because people can't type the date. Use a date picker, which has typed segments as well as the calendar.
- Only a few dates are open, such as three appointment days. List them as Radio options written in full, such as Thursday 22 October 2026.

<DocsAnatomy>

1. **Container**

   Holds one month, with a 1 border, radius 12, a medium shadow and padding 4. The date grid is a fixed 308 wide. In code it is Calendar, or RangeCalendar for a range.

2. **Previous month**

   A 36 icon-only ghost button. Its icon points the other way in Dhivehi.

3. **Month**

   The visible month name. Under Dhivehi it comes from Veli's own table of month names.

4. **Next month**

   The same button as previous month, named Next month.

5. **Year picker**

   The year and a 36 caret button. It opens a list of 10 years either side of the visible year. Screen readers hear year.

6. **Weekday headers**

   Seven day names, starting on Sunday. Short names in English, full names in Dhivehi; change them with weekdayStyle.

7. **Day**

   A 44 x 44 cell with the date number. Days of the previous and next month show in a lighter text colour. In code it is CalendarCell.

8. **Today marker**

   A 4 x 4 dot under today's number. Screen readers hear Today before the date, so today never relies on colour alone.

9. **Selected day**

   Filled with `calendar/day-selected`, or with `button/danger/default` while the calendar is invalid. In RangeCalendar the start and end are rounded and the days between are tinted.

10. **Today button**

optional and off by default. A full-width primary ghost button under a divider that focuses and selects today. In code it is showTodayButton and todayButtonLabel. 11. **Error message**

shows below the grid while the calendar is invalid, with a 16 warning icon and the message in `text/danger/muted`. In code it is isInvalid and errorMessage.

</DocsAnatomy>

## Content guidelines

### Accessible name

Name a calendar with what the date is for, in sentence case. Pass a Dhivehi name under language dv. Leave the role word out of the name.

| Do               | Don't                                          |
| :--------------- | :--------------------------------------------- |
| Appointment date | Calendar (says what it is, not what it is for) |
| Leave dates      | No name at all                                 |

### Show the choice as text

Write the chosen date or range in full next to the calendar.

| Do                       | Don't                                                   |
| :----------------------- | :------------------------------------------------------ |
| Thursday 22 October 2026 | The highlighted day as the only sign of what was chosen |
| 1 to 5 March 2026        |                                                         |

Add the weekday before the date, with no comma, when people need to plan around it: appointments, deadlines and service closures.

### Closed days

Say in text when the service is closed: Open Sunday to Thursday, except public holidays.

### Error messages

Write a calendar error as the rule people must follow, with the dates, and leave the full stop off a one-sentence error.

| Do                                                        | Don't                                                                          |
| :-------------------------------------------------------- | :----------------------------------------------------------------------------- |
| Choose a date between 23 October and 21 December 2026     | Pick a date within the allowed window. (Pick, no dates named, and a full stop) |
| Choose a date from Sunday to Thursday in the next 60 days |                                                                                |

### Today button

Keep the label as Today (މިއަދު in Dhivehi). If you override todayButtonLabel, pass the text in both languages.

### Built-in strings

Calendar has these built-in strings: Today (todayButtonLabel), the Dhivehi month and weekday names from Veli's own table, and the month and year button names. Day cell names, the grid name and the React Aria announcements, such as Selected Date and Today, stay in English. Only the Today label and the calendar's name can be overridden.

- **Today button**: turn it on with showTodayButton when people often need today. It is off by default. In single date mode it focuses and selects today; in a range it sets a one-day range; in read-only mode it only moves focus. It is disabled when today is outside minValue and maxValue, unavailable or invalid.
- **Error message**: pair isInvalid with a short errorMessage that says what to do.
- **Sixth week**: months that need it get a sixth row, so the height changes from month to month. Code adds it on its own; in Figma, set the days for the month you show.

## Behaviour

- **Where focus starts**: when the calendar gets focus, the selected date is focused, or today when nothing is selected. focusedValue sets the visible month.
- **Month and year**: the header has previous and next month buttons, the month name and a year picker with 10 years either side of the visible year.
- **Choosing a range**: in RangeCalendar the first Enter, Space, tap or click sets the start and the second sets the end. Moving or hovering previews the range, and Escape cancels a range in progress. On touch, people can also drag across dates.
- **Controlled**: use value and onChange to own the selected date, and focusedValue with onFocusChange to keep externally changed dates in view.
- **Six-week months**: a sixth row of weeks is added for months that need it, so the height changes from month to month.
- **One month at a time**: the calendar has no multi-month layout.
- **Closed days**: use isDateUnavailable for days the service is closed, such as Fridays, Saturdays and public holidays, and say so in text near the calendar. Set the bookable window with minValue and maxValue.
- **No motion**: don't animate moving between days or months. People repeat it many times in a row.

## Layout

- The surface is 318 wide with 44 x 44 day cells. It shrinks within narrower containers while keeping seven columns and 44 high rows. Weekday text may abbreviate at narrow widths.
- Give flex and grid parents min-w-0, and don't force a minimum width on the calendar.
- Reserve enough horizontal space for the grid, and place several calendars in one column on narrow layouts.

### Controlled selection and focus

Use `value` and `onChange` to own the selected date. Use `focusedValue` and `onFocusChange` to keep externally changed dates in view.

<div className="preview mb-4 min-w-0 rounded-lg border p-4">
  <CalendarControlledDemo client:load />
</div>

```tsx
const [value, setValue] = useState(parseDate('2026-10-15'));
const [focusedValue, setFocusedValue] = useState(value);

<Calendar
  aria-label="Appointment calendar"
  value={value}
  focusedValue={focusedValue}
  onFocusChange={setFocusedValue}
  onChange={(next) => {
    setValue(next);
    setFocusedValue(next);
  }}
/>;
```

## Date range

Select a start date, then an end date. Endpoints have a primary fill and dates between them form a continuous band, mirrored in RTL. A single-day range uses a circular selection.

<div className="preview mb-4 min-w-0 rounded-lg border p-4">
  <CalendarRangeDemo client:load />
</div>

```tsx
const [value, setValue] = useState({
  start: parseDate('2026-10-13'),
  end: parseDate('2026-10-20'),
});

<RangeCalendar aria-label="Trip dates" value={value} onChange={setValue} showTodayButton />;
```

For uncontrolled ranges, pass the same `{ start, end }` shape to `defaultValue`.

## Constraints and validation

`minValue` and `maxValue` disable dates outside the allowed window. `isDateUnavailable` marks blackout dates with a strikethrough; they remain keyboard-focusable but cannot be selected. Ranges cannot cross unavailable dates unless `allowsNonContiguousRanges` is enabled.

## Today and responsive behavior

`showTodayButton` defaults to `false`. When enabled, Today focuses and selects today's date, or sets a one-day range. In read-only mode it only changes focus. It is disabled when today is outside the allowed window or unavailable. `todayButtonLabel` overrides the English or Dhivehi default.

Use `VeliProvider` with `language="en"` or `language="dv"` for locale, direction, and typography; use `colorScheme="light"`, `"dark"`, or `"system"` for theme. Load Veli's documented fonts and stylesheet. Month/weekday labels, navigation names, and Today are localized. Consumer-provided labels and errors must be localized by the application.

Both calendars start weeks on **Sunday**, independent of locale. Override `firstDayOfWeek` when needed. Weekday labels default to `short` in LTR and `long` in RTL; `weekdayStyle` can override this.

The default surface is 318 CSS pixels wide with 44-pixel day targets. It shrinks within narrower containers while retaining seven columns and 44-pixel row heights. Give flex/grid parents `min-w-0`; avoid forcing a minimum width on the calendar. Use `gridClassName` for an intentional compact grid and `className` for the surface. Weekday text may visually abbreviate at narrow widths; full weekday names remain accessible.

## API Reference

Calendar and RangeCalendar compose their corresponding React Aria calendar primitives.

### Calendar and RangeCalendar

Veli-specific props shared by both selection modes.

| Prop               | Type                            | Default                       | Description                                        |
| :----------------- | :------------------------------ | :---------------------------- | :------------------------------------------------- |
| `className`        | `string`                        | -                             | Merged surface styles.                             |
| `gridClassName`    | `string`                        | -                             | Merged grid styles.                                |
| `weekdayStyle`     | `'narrow' \| 'short' \| 'long'` | `short` in LTR; `long` in RTL | Weekday header format.                             |
| `showTodayButton`  | `boolean`                       | `false`                       | Shows the Today action.                            |
| `todayButtonLabel` | `string`                        | Localized string              | Overrides the Today label.                         |
| `errorMessage`     | `string`                        | -                             | Error text associated with selected invalid dates. |

### React Aria Calendar and RangeCalendar

React Aria's corresponding Calendar and RangeCalendar props pass through, except `children`. Veli owns the internal composition.

| Prop                                      | Type                                                          | Default | Description                                                     |
| :---------------------------------------- | :------------------------------------------------------------ | :------ | :-------------------------------------------------------------- |
| `value` / `defaultValue`                  | `DateValue` or `{ start: DateValue; end: DateValue }`         | -       | Controlled / initial selection. `value` also accepts `null`.    |
| `onChange`                                | `(value) => void`                                             | -       | Called with the component's selection shape.                    |
| `focusedValue` / `defaultFocusedValue`    | `DateValue`                                                   | -       | Controlled / initial focused date.                              |
| `onFocusChange`                           | `(date: DateValue) => void`                                   | -       | Focused-date changes.                                           |
| `firstDayOfWeek`                          | `'sun' \| 'mon' \| 'tue' \| 'wed' \| 'thu' \| 'fri' \| 'sat'` | `'sun'` | First weekday, independent of locale.                           |
| `minValue` / `maxValue`                   | `DateValue`                                                   | -       | Inclusive selectable boundaries.                                |
| `isDateUnavailable`                       | `(date: DateValue) => boolean`                                | -       | Marks blackout dates.                                           |
| `isDisabled` / `isReadOnly` / `isInvalid` | `boolean`                                                     | `false` | Disabled, read-only, or invalid state.                          |
| `allowsNonContiguousRanges`               | `boolean`                                                     | `false` | RangeCalendar only; permits a range spanning unavailable dates. |
| `aria-label` / `aria-labelledby`          | `string`                                                      | -       | Supply an accessible name.                                      |

Both wrappers inherit their corresponding React Aria Calendar props except `children`; their internal layout is fixed. `CalendarHeader` and `CalendarGridHeader` remain named exports for existing custom React Aria compositions. No new import or migration is required.

## Accessibility

Tab reaches the navigation controls and active date. Arrow keys move between dates, Home/End move within the week, Page Up/Down change months, and Enter/Space selects a date. Horizontal navigation follows the active direction. In a range calendar, select the start and end with the same keyboard controls. The year menu supports keyboard selection, Escape dismissal, and focus return.

Selected, unavailable, disabled, and invalid dates expose React Aria semantics. Focus rings remain visible, including in reduced-motion mode. Color is supplemented by selection announcements, unavailable-date strikethrough, and error text.

## Keyboard

The grid is one Tab stop, next to the month buttons and the year picker.

| Key                                   | Action                                                                          |
| :------------------------------------ | :------------------------------------------------------------------------------ |
| Tab                                   | Moves between the month buttons, the year picker, the grid and the Today button |
| Left and Right arrows                 | Move one day, mirrored in Dhivehi so Left always moves to the day on the left   |
| Up and Down arrows                    | Move one week                                                                   |
| Page Up and Page Down                 | Move one month                                                                  |
| Shift + Page Up and Shift + Page Down | Move one year                                                                   |
| Home and End                          | Move to the first and last day of the month                                     |
| Enter or Space                        | Select the focused day, or set a range start or end                             |
| Escape                                | Cancel a range in progress, or close the year list                              |

Home and End go to the first and last day of the month, as React Aria does, where the APG date picker goes to the start and end of the week. Veli keeps this on purpose.

## Screen readers

- Give the calendar an accessible name with aria-label or aria-labelledby. The grid is named with that label and the visible month, such as "Appointment date, October 2026".
- Each day cell is named with the full date. Today is announced as Today before the date.
- The calendar announces the new month when people move to it, and the date when they select it. These announcements are in English under Dhivehi.
- Selected, unavailable, disabled and invalid dates expose their state.

## Focus

Keyboard focus shows a visible focus ring around the day. It shows only for keyboard focus, never on click or tap, and sits outside the day, so focus doesn't move the grid. It stays visible with reduced motion.
