# Badge

Use Badge for compact status, category, and count labels. For page-level banners, use [Alert](/docs/alert/). For temporary notifications, use [Toast](/docs/toast/).

## Import

```tsx
import { Badge } from '@veli-design/react/badge';
```

## Usage

<div className="preview mb-4 rounded-lg border p-4">
  <BadgeUsageDemo client:visible />
</div>

```tsx
<Badge intent="positive" appearance="subtle">
  Approved
</Badge>
```

## Appearances

`outline`, `subtle`, and `emphasis` change the surface treatment. Size label badges with `sm` or `md`.

<div className="preview mb-4 rounded-lg border p-4">
  <BadgeAppearancesDemo client:visible />
</div>

```tsx
<Badge intent="info" appearance="outline">Outline</Badge>
<Badge intent="info" appearance="subtle">Subtle</Badge>
<Badge intent="info" appearance="emphasis">Emphasis</Badge>
```

## Counter mode

Pass `counter` or `count` for a numeric pill. Values above `max` render as `{max}+`.

<div className="preview mb-4 rounded-lg border p-4">
  <BadgeCounterDemo client:visible />
</div>

```tsx
<Badge intent="danger" counter count={5} />
<Badge intent="neutral" counter count={128} max={99} />
<Badge count={7} appearance="emphasis" intent="danger" size="sm" />
```

When overlaying a counter on an icon, put the icon in a button (or similar padded control). A bare icon leaves too little room, so the badge clips the glyph.

<div className="preview mb-4 rounded-lg border p-4">
  <BadgeCounterOnIconDemo client:visible />
</div>

```tsx
<div className="relative inline-flex">
  <Button
    iconOnly
    intent="secondary"
    appearance="transparent"
    size="md"
    aria-label="5 notifications"
  >
    <Bell aria-hidden size={20} weight="regular" />
  </Button>
  <Badge
    counter
    count={5}
    appearance="emphasis"
    intent="danger"
    size="sm"
    className="absolute -top-0.5 -end-0.5"
    aria-hidden
  />
</div>
```

## Status dots

`size="xs"` renders an 8px status dot without a label.

<div className="preview mb-4 rounded-lg border p-4">
  <BadgeStatusDotsDemo client:visible />
</div>

```tsx
<Badge appearance="emphasis" intent="positive" size="xs" aria-label="Online" />
<Badge appearance="emphasis" intent="cautious" size="xs" aria-label="Away" />
<Badge appearance="emphasis" intent="danger" size="xs" aria-label="Busy" />
<Badge appearance="emphasis" intent="neutral" size="xs" aria-label="Offline" />
```

## API Reference

| Prop          | Type                                                                                                                                | Default     | Description                                              |
| :------------ | :---------------------------------------------------------------------------------------------------------------------------------- | :---------- | :------------------------------------------------------- |
| `intent`      | `'neutral' \| 'info' \| 'positive' \| 'cautious' \| 'warning' \| 'danger' \| 'magenta' \| 'indigo' \| 'brand' \| 'green' \| 'lime'` | `'neutral'` | Semantic color of the badge.                             |
| `appearance`  | `'emphasis' \| 'outline' \| 'subtle'`                                                                                               | `'outline'` | Visual treatment of the badge surface.                   |
| `size`        | `'xs' \| 'sm' \| 'md'`                                                                                                              | `'md'`      | Badge size. `xs` is the status-dot mode.                 |
| `counter`     | `boolean`                                                                                                                           | `false`     | Switches to a numeric counter pill.                      |
| `count`       | `number`                                                                                                                            | -           | Value shown in counter mode (also enables counter mode). |
| `max`         | `number`                                                                                                                            | `99`        | Cap above which the count renders as `{max}+`.           |
| `leadingIcon` | `ReactNode`                                                                                                                         | -           | Icon rendered before the label.                          |
| `className`   | `string`                                                                                                                            | -           | Layout class on the root.                                |

All other `span` attributes are supported.

## Accessibility

- Label badges expose their text through the rendered label.
- `size="xs"` status dots are `aria-hidden` unless you pass `aria-label` or `aria-labelledby`.
- Counter badges should include `aria-label` when the count is not clear from visible text alone.
- When a counter overlays an icon button, put the count in the button’s `aria-label` and mark the badge `aria-hidden`.
- Badge is a non-interactive `span` by default. Wrap it in a button or link when it should be actionable.

## RTL and Language

In RTL, the leading icon and label follow `dir`. Localized label copy is fine; status dots still need an `aria-label` in the active language.
