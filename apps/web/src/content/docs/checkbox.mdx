# Checkbox

The Checkbox component supports checked, unchecked, and indeterminate states with both square and round styles.

## Import

```tsx
import { Checkbox } from '@tradenetcorp/coral-ui/checkbox';
```

import { Checkbox } from '@tradenetcorp/coral-ui/checkbox';

## Usage

<div className="preview p-4 border rounded-lg bg-surface-100 mb-4">
  <div className="flex flex-col gap-[12px]">
    <Checkbox client:visible>Default</Checkbox>
    <Checkbox client:visible defaultSelected>
      Checked
    </Checkbox>
    <Checkbox client:visible isIndeterminate>
      Indeterminate
    </Checkbox>
  </div>
</div>

```tsx
<Checkbox>Default</Checkbox>
<Checkbox defaultSelected>Checked</Checkbox>
```

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `shape` | `'square' \| 'round'` | `'square'` | Visual style of the control. |
| `isIndeterminate` | `boolean` | `false` | Displays a dash indicator state. |
| `isDisabled` | `boolean` | `false` | Disables interaction and applies disabled styling. |

*Note: All other `react-aria-components` Checkbox props are supported, excluding `className` and `style` overrides.*
