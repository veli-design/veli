# Switch

<DocsTab id="overview">

A switch turns a setting on or off, and the change takes effect straight away. Use it for preferences such as notifications. Use a checkbox for choices that are submitted with a form.

<DocsResources
  source="https://github.com/veli-design/veli/blob/main/packages/react/src/switch.tsx"
  storybook="https://storybook.veli.design/?path=/docs/components-switch--docs"

## When to use

### Use a switch when

- A setting has two mutually exclusive states, on and off.
- Changing the setting can take effect immediately, without a save step.
- The current state should be visible at a glance.

### Don't use a switch when

- The value is submitted as part of a form, or stands for agreement or consent. Use a [checkbox](/docs/components/checkbox/).
- People must turn something on before they can continue. Use a [checkbox](/docs/components/checkbox/) with isRequired: a switch has no required or invalid state.
- People must choose one value from more than two named options. Use a [radio](/docs/components/radio/) group or a [select](/docs/components/select/).
- The control runs an action or the change needs confirming. Use a [button](/docs/components/button/).

<DocsAnatomy>

1. **Track**

   The pill-shaped body, 32 x 16, 40 x 20 or 48 x 24, fully rounded. In the default appearance it has a border when off and fills green when on. The subtle appearance has a filled track.

2. **Handle**

   The round thumb. It sits at the start when off and moves to the end when on, growing by 2: 10, 14 or 18 off and 12, 16 or 20 on.

3. **Check**

   Shows at the start of the track when on, in the default appearance only.

4. **Label**

   Names the setting, 8 after the track. It is part of the control, so clicking it toggles the switch. In code it is the Switch children.

</DocsAnatomy>

A switch has no description or error message. Put any help text below it yourself.

## Content guidelines

### Labels

Name the setting in a few words, in sentence case. Word it positively, so on means yes. Don't ask a question, give an instruction or add punctuation, and keep the label the same when the state changes.

| Do                           | Don't                                   |
| :--------------------------- | :-------------------------------------- |
| Email updates                | Do you want email updates? (a question) |
| SMS reminders                | Turn on email updates (an instruction)  |
| Appointment reminders by SMS | Disable emails (negative)               |
|                              | Email updates: (colon)                  |
|                              | Notifications. (full stop)              |
|                              | Email updates: On (state in the label)  |

### Help text

Switch has no description. When a setting needs context, put one short line of help below it in body sm regular, `text/base/muted`, and link it to the switch with aria-describedby in code. Leave off the full stop.

| Do                                              |
| :---------------------------------------------- |
| We send reminders 1 day before your appointment |

### Failed saves

A switch has no invalid state. If a change fails to save, switch it back and say why nearby. A switch left on after a failed save tells people the setting changed when it did not.

| Do                                               | Don't                                  |
| :----------------------------------------------- | :------------------------------------- |
| Email updates could not be turned on. Try again. | Error (says nothing about what failed) |

### No success messages

Don't show a success message when a switch turns on or off. People can already see the change.

### Dhivehi copy

Switch has no built-in text. Pass the label, any aria-label and the help text in English and Dhivehi. Write Dhivehi natively rather than translating word for word, and keep it as short as the English.

The track, handle and label grow together. In code, size defaults to md.

- Use **sm** (track 32 x 16, body sm medium label) for dense lists, tables and panel settings. Use the default appearance at this size, because the subtle off track is below 3:1.
- Use **md** (track 40 x 20, body sm medium label) by default.
- Use **lg** (track 48 x 24, body md medium label) for settings pages with few options.

| State         | When                                 | Visual change                                                |
| :------------ | :----------------------------------- | :----------------------------------------------------------- |
| Off           | Default                              | A border and the handle at the start                         |
| On            | isSelected                           | A green track, the check and the handle at the end           |
| Hover, off    | Pointer over the switch or its label | The border darkens. Subtle: the track darkens                |
| Hover, on     | Pointer over the switch              | The track darkens                                            |
| Pressed       | While pressing                       | The track scales to 1.04 and the handle to 0.96              |
| Focus         | Keyboard focus                       | Focus ring around the track: 2px in `border/focus`, offset 2 |
| Disabled, off | isDisabled                           | Muted track and label; skipped by Tab                        |
| Disabled, on  | isDisabled                           | The check stays; the track turns grey                        |
| Read only     | isReadOnly                           | Looks the same as default but can't be toggled               |

Switch has no required, invalid, indeterminate or loading state.

## Behaviour

- **Apply at once**: apply a switch change straight away. Your app owns saving and the message if a save fails.
- **Controlled or uncontrolled**: pass isSelected with onChange to control it, or defaultSelected for an uncontrolled switch. Control it when content around it must react to the setting.
- **No surprises**: turning a switch on or off only changes the setting, never the page, the form or the focus.
- **Read only, not disabled**: use isReadOnly for a switch whose value people need to see but can't change here. A disabled switch is skipped by Tab and left out of form data, so screen reader users never learn its value.
- **Form data**: only selected, enabled switches submit their name and value.
- **Whole row**: the label is part of the control, so clicking it toggles the switch.
- **Wrapping**: long labels wrap without shrinking the track. Place several switches in a vertical stack or a responsive grid.
- **Styling**: Switch takes no style overrides. Its className only sets the outer layout.

Use `defaultSelected` for the initial uncontrolled state, or `isSelected` with `onChange` for controlled state. Keep the label stable when the setting changes. The application owns persistence and feedback for failed saves.

```tsx
const [selected, setSelected] = useState(false);

<Switch isSelected={selected} onChange={setSelected}>
  Notifications
</Switch>;
```

Use `sm`, `md`, or `lg`; `md` is the default. Tracks measure 32 × 16, 40 × 20, and 48 × 24 pixels. The root label provides a minimum 24-pixel hit height. Long labels wrap without shrinking the track.

## States

Disabled switches cannot receive keyboard focus and are omitted from form data. Read-only switches retain focus and their selected form value, but cannot be toggled.

## API Reference

Switch is a Veli control on React Aria [`Switch`](https://react-spectrum.adobe.com/react-aria/Switch.html), which wraps a native checkbox with `role="switch"`. Props below follow that stack.

### Switch

Veli-specific props for the composed control.

| Prop         | Type                    | Default     | Description                                         |
| :----------- | :---------------------- | :---------- | :-------------------------------------------------- |
| `appearance` | `'default' \| 'subtle'` | `'default'` | Outlined or filled off track; checkmark in default. |
| `size`       | `'sm' \| 'md' \| 'lg'`  | `'md'`      | Track size and label typography.                    |
| `children`   | `ReactNode`             | -           | Visible inline label.                               |
| `className`  | `string`                | -           | Layout class on the root (margin, flex/grid).       |
| `ref`        | `Ref<HTMLLabelElement>` | -           | Forwarded to the outer label.                       |

### React Aria Switch

React Aria's headless Switch. These props pass through. The remaining DOM and ARIA attributes follow React Aria's API, except the exclusions below.

| Prop               | Type                                  | Default | Description                                        |
| :----------------- | :------------------------------------ | :------ | :------------------------------------------------- |
| `isSelected`       | `boolean`                             | -       | Controlled on/off state.                           |
| `defaultSelected`  | `boolean`                             | `false` | Initial uncontrolled on/off state.                 |
| `onChange`         | `(isSelected: boolean) => void`       | -       | Called when selection changes.                     |
| `isDisabled`       | `boolean`                             | `false` | Prevents interaction, focus, and form submission.  |
| `isReadOnly`       | `boolean`                             | `false` | Prevents toggling while retaining focus and value. |
| `autoFocus`        | `boolean`                             | `false` | Focuses the switch on mount.                       |
| `inputRef`         | `RefObject<HTMLInputElement \| null>` | -       | Ref to the native input.                           |
| `slot`             | `string \| null`                      | -       | Slot for React Aria context composition.           |
| `render`           | `function`                            | -       | Custom root rendering with React Aria root props.  |
| `aria-label`       | `string`                              | -       | Accessible name when the visible label is omitted. |
| `aria-labelledby`  | `string`                              | -       | IDs of external label elements.                    |
| `aria-describedby` | `string`                              | -       | IDs of external descriptions.                      |

Focus, keyboard, and hover callbacks also pass through:

| Prop            | Type                             | Description                         |
| :-------------- | :------------------------------- | :---------------------------------- |
| `onFocus`       | `(event: FocusEvent) => void`    | Called when the switch gains focus. |
| `onBlur`        | `(event: FocusEvent) => void`    | Called when the switch loses focus. |
| `onFocusChange` | `(isFocused: boolean) => void`   | Called when focus changes.          |
| `onKeyDown`     | `(event: KeyboardEvent) => void` | Called on key press.                |
| `onKeyUp`       | `(event: KeyboardEvent) => void` | Called on key release.              |
| `onHoverStart`  | `(event: HoverEvent) => void`    | Called when pointer hover starts.   |
| `onHoverEnd`    | `(event: HoverEvent) => void`    | Called when pointer hover ends.     |
| `onHoverChange` | `(isHovered: boolean) => void`   | Called when hover changes.          |

`FocusEvent` and `KeyboardEvent` are React event types. `HoverEvent` is the React Aria hover event type.

Not forwarded from React Aria Switch:

| Prop        | Why                                                               |
| :---------- | :---------------------------------------------------------------- |
| `children`  | Replaced by Veli's inline label content; no render function.      |
| `className` | Replaced by Veli's layout string on the root; no render function. |
| `style`     | Not supported.                                                    |

The standalone Switch does not support `isRequired`, `isInvalid`, `validate`, indeterminate, or loading states. Descriptions and setting-row layouts belong to consumer composition. The track, handle, and checkmark are private.

### Native checkbox

The native `<input type="checkbox" role="switch">` that React Aria wraps. These attributes are applied to that element.

| Prop    | Type     | Default | Description                    |
| :------ | :------- | :------ | :----------------------------- |
| `id`    | `string` | -       | Native input ID.               |
| `name`  | `string` | -       | Native form field name.        |
| `value` | `string` | `'on'`  | Value submitted when selected. |
| `form`  | `string` | -       | ID of the associated form.     |

Only selected, enabled switches submit `name=value`. Native form reset restores the uncontrolled initial selection. Changing `defaultSelected` after mounting does not reset it.

## Accessibility

- Give the switch visible `children`, or use `aria-label` / `aria-labelledby` when the label is external or hidden. Avoid interactive elements inside the label.
- Tab focuses the switch; Space and pointer activation toggle on release.
- Associate external helper text with `aria-describedby`, using unique IDs for each setting.
- Reduced motion removes the press scaling and thumb animation. Forced-colors mode uses system colors and a visible keyboard focus outline.

```tsx
<div className="flex items-start gap-4">
  <div className="min-w-0 flex-1">
    <span id="email-label">Email notifications</span>
    <p id="email-description">Receive alerts and updates via email</p>
  </div>
  <Switch aria-labelledby="email-label" aria-describedby="email-description" defaultSelected />
</div>
```

How the switch works with keyboards, screen readers and contrast themes, and what you still need to do. Switch is a native checkbox input with the switch role, built on React Aria.

## Keyboard

| Key         | Action                              |
| :---------- | :---------------------------------- |
| Tab         | Moves focus to the switch           |
| Shift + Tab | Moves focus to the previous element |
| Space       | Toggles the switch                  |

Enter does not toggle a switch. Disabled switches are skipped by Tab; read-only switches can be focused but not toggled.

## Screen readers

- The switch is announced as a switch that is on or off.
- The visible label is part of the control and is its accessible name. Without visible text, use aria-label, or aria-labelledby pointing at a heading that names the setting. Any accessible name must contain the visible label.
- Help text below the switch is not linked automatically. Link it with aria-describedby, using a unique id for each setting.
- The track, handle and check are hidden from assistive technology.

## Focus

- Keyboard focus shows a 2px ring in `border/focus` around the track, offset 2 on `bg/surface/raised`. It appears for keyboard focus only.
- State is never shown by colour alone: the handle position, and the check in the default appearance, show it as well as the green track.

## Disabled

Disabled switches can't be focused or changed, and are left out of form data. Use isReadOnly instead when people need to find and hear the value.

## Target size

The label is part of the target, and the row is at least 24 high at every size, so the whole row toggles the switch.

## Contrast

Contrast against `bg/surface/raised`, in the light and dark themes:

| Element                         | Light | Dark   | Minimum |
| :------------------------------ | :---- | :----- | :------ |
| Label text                      | 8.0:1 | 7.3:1  | 4.5:1   |
| Off border, default appearance  | 3.4:1 | 3.0:1  | 3:1     |
| On track                        | 3.3:1 | 4.8:1  | 3:1     |
| Handle on the on track          | 3.2:1 | 3.6:1  | 3:1     |
| Off track, subtle               | 1.9:1 | 1.2:1  | 3:1     |
| Handle on the off track, subtle | 1.9:1 | 14.5:1 | 3:1     |

Use appearance default wherever people must recognise the off state, including dense lists at size sm. The subtle off track is below 3:1. Don't override the switch tokens with custom colours.

## Forced colours

In Windows contrast themes the switch uses system colours, so the track, handle and focus ring stay visible.

## Reduced motion

When the user prefers reduced motion, the handle moves without animation and the press scaling is turned off. Nothing extra is needed from you.

## Right to left

Set the language with VeliProvider (language dv). It sets the direction and the language, mirrors the label order and handle travel, and applies the Dhivehi label style. Pass Dhivehi labels and help text yourself: Switch has no built-in text.
