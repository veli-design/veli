# Divider

`Divider` is a small structural primitive for separating related content. It wraps React Aria's `Separator` and applies Veli border tokens for horizontal and vertical layouts.

## Import

```tsx
import { Divider } from '@tradenetcorp/veli-ui/divider';
```

## API Reference

| Prop          | Type                         | Description                                                                                         |
| :------------ | :--------------------------- | :-------------------------------------------------------------------------------------------------- |
| `orientation` | `'horizontal' \| 'vertical'` | Controls whether the divider runs across rows or between inline items.                              |
| `elementType` | `string`                     | Changes the rendered HTML element when you need something other than the default separator element. |
| `className`   | `string`                     | Adds local visual overrides on top of the Veli base styling.                                        |

All remaining supported React Aria `Separator` props can still be passed through this wrapper.
