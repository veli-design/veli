# DatePicker

Use DatePicker when people need to type a date or choose one from a calendar. Its date segments and calendar share one value. Use [DateField](/docs/date-field/) when a calendar is unnecessary, or [Calendar](/docs/calendar/) for an embedded date selector.

## Import

```tsx
import { DatePicker } from '@veli-design/react/date-picker';
```

## Usage

<div className="preview mb-4 rounded-lg border p-4">
  <DatePickerUsageDemo client:load />
</div>

```tsx
<DatePicker
  label="Appointment date"
  isOptional
  infoTooltip="Type a date or choose one from the calendar."
  description="Type a date or choose one from the calendar."
/>
```

Type into the date segments, use the arrow keys to change a segment, or open the calendar button. The calendar's Today action is shown by default.

## Appearances

`default` uses the underline shell. `outline` draws a bordered field. Size the field with `sm`, `md`, or `lg`. Like DateField, width follows its container; apply a layout class to the root when a fixed width is needed.

<div className="preview mb-4 rounded-lg border p-4">
  <DatePickerAppearancesDemo client:visible />
</div>

```tsx
<DatePicker label="Default" />
<DatePicker appearance="outline" label="Outline" />
```

The field uses the `radius/field` token (10 px). The calendar popover is 316 px wide with 44 px day targets where space permits, and clamps to the viewport on narrow phones. Heights stay 36, 44, and 52 px for `sm`, `md`, and `lg`, including Dhivehi. The calendar icon is 20 px and the info icon is 16 px. The popover opens 4 px below the field.

## Validation

When `isInvalid` is set, `errorMessage` replaces the helper text. `minValue`, `maxValue`, and `isDateUnavailable` limit selectable dates.

<div className="preview mb-4 rounded-lg border p-4">
  <DatePickerValidationDemo client:visible />
</div>

```tsx
<DatePicker label="Service date" isInvalid errorMessage="Enter a valid service date." />
```

Give the field a `name` to submit its completed value as an ISO string. Use `value` and `onChange` for a controlled value, or `defaultValue` for an initial value. `granularity` adds editable time segments for date-time values.

When the form stores ISO `yyyy-MM-dd` strings, convert with `isoDateToDateValue` / `dateValueToIsoDate` from `@veli-design/react/form`. You can also hold `DateValue` objects in form state. See [Forms](/patterns/forms/) for form-library integration.

## API Reference

DatePicker is a Veli field on React Aria [`DatePicker`](https://react-spectrum.adobe.com/react-aria/DatePicker.html). Props below follow that stack.

### DatePicker

Veli-specific props for the composed field.

| Prop                    | Type                     | Default          | Description                                                            |
| :---------------------- | :----------------------- | :--------------- | :--------------------------------------------------------------------- |
| `appearance`            | `'default' \| 'outline'` | `'default'`      | Underline or bordered field.                                           |
| `size`                  | `'sm' \| 'md' \| 'lg'`   | `'md'`           | Field size.                                                            |
| `label`                 | `ReactNode`              | -                | Visible label.                                                         |
| `isOptional`            | `boolean`                | `false`          | Shows localized Optional beside the label. Hidden when `isRequired`.   |
| `infoTooltip`           | `ReactNode`              | -                | Content for the header info tooltip.                                   |
| `infoTooltipAriaLabel`  | `string`                 | Localized string | Accessible name for the info tooltip trigger.                          |
| `description`           | `ReactNode`              | -                | Helper text beneath the field.                                         |
| `errorMessage`          | `ReactNode`              | -                | Error text shown when `isInvalid`.                                     |
| `showRequiredIndicator` | `boolean`                | `true`           | Shows the required asterisk when `isRequired`.                         |
| `calendarButtonLabel`   | `string`                 | Localized string | Accessible name for the calendar trigger.                              |
| `triggerRef`            | `Ref<HTMLButtonElement>` | -                | Ref to the calendar trigger, so form libraries can focus it on errors. |
| `showTodayButton`       | `boolean`                | `true`           | Shows the Today action in the calendar.                                |
| `todayButtonLabel`      | `string`                 | Localized string | Overrides the Today action text.                                       |
| `className`             | `string`                 | -                | Layout class on the root (width, margin, flex/grid).                   |
| `inputClassName`        | `string`                 | -                | Layout class on the input shell.                                       |
| `popoverClassName`      | `string`                 | -                | Class on the calendar popover.                                         |
| `calendarClassName`     | `string`                 | -                | Class on the calendar surface.                                         |

### React Aria DatePicker

React Aria’s headless [`DatePicker`](https://react-spectrum.adobe.com/react-aria/DatePicker.html#props). These props pass through. The React Aria docs cover the rest, except the exclusions below.

| Prop                      | Type                                      | Default | Description                                        |
| :------------------------ | :---------------------------------------- | :------ | :------------------------------------------------- |
| `value`                   | `DateValue \| null`                       | -       | Controlled value.                                  |
| `defaultValue`            | `DateValue`                               | -       | Uncontrolled initial value.                        |
| `onChange`                | `(value: DateValue \| null) => void`      | -       | Called when the value changes.                     |
| `placeholderValue`        | `DateValue`                               | -       | Placeholder shape and initial calendar view.       |
| `granularity`             | `'day' \| 'hour' \| 'minute' \| 'second'` | -       | Smallest editable segment.                         |
| `hourCycle`               | `12 \| 24`                                | -       | Forces 12-hour or 24-hour time when time is shown. |
| `hideTimeZone`            | `boolean`                                 | -       | Hides the time zone segment for zoned values.      |
| `shouldForceLeadingZeros` | `boolean`                                 | -       | Keeps segment values zero-padded where applicable. |
| `minValue`                | `DateValue`                               | -       | Lowest allowed date/time.                          |
| `maxValue`                | `DateValue`                               | -       | Highest allowed date/time.                         |
| `isDateUnavailable`       | `(date: DateValue) => boolean`            | -       | Blocks unavailable calendar dates.                 |
| `isDisabled`              | `boolean`                                 | `false` | Disables editing and calendar opening.             |
| `isInvalid`               | `boolean`                                 | `false` | Marks the field invalid.                           |
| `isReadOnly`              | `boolean`                                 | `false` | Prevents editing and calendar opening.             |
| `isRequired`              | `boolean`                                 | `false` | Marks the field required.                          |
| `name`                    | `string`                                  | -       | Submits the value in forms as an ISO string.       |
| `validate`                | `function`                                | -       | Custom validation.                                 |
| `autoFocus`               | `boolean`                                 | `false` | Focuses the field on mount.                        |
| `shouldCloseOnSelect`     | `boolean`                                 | -       | Controls calendar closing after selection.         |

Not forwarded from React Aria `DatePicker`:

| Prop        | Why                                                |
| :---------- | :------------------------------------------------- |
| `children`  | Veli owns the field composition.                   |
| `style`     | Not supported.                                     |
| `className` | Replaced by Veli’s layout `className` on the root. |

## Accessibility

Each date segment is individually editable and focusable. The calendar button is a separate control. Tab reaches the field and button; arrow keys and typing edit segments; Escape closes the calendar and returns focus. Helper and error content are linked to the picker. The Today action remains disabled when today's date is unavailable.

## RTL and Language

Set `language` on `VeliProvider`. English and caller-supplied locales keep their date format. Dhivehi uses native RTL labels and calendar text, with an English Gregorian formatter scoped to its editable field to keep Latin day/month/year segments stable across browser engines. The numeric field runs LTR and aligns to the right. Calendar navigation mirrors in RTL, while date values remain semantic dates rather than formatted strings.

<div className="preview mb-4 rounded-lg border p-4">
  <DatePickerRtlDemo client:load />
</div>

```tsx
import { parseDate } from '@internationalized/date';
import { DatePicker } from '@veli-design/react/date-picker';
import { VeliProvider } from '@veli-design/react/provider';

export default function DatePickerLanguageDemo() {
  return (
    <VeliProvider language="dv">
      <DatePicker
        label="އެޕޮއިންޓްމަންޓް ތާރީޚު"
        description="އެހީތެރިވެދޭ ލިޔުން"
        defaultValue={parseDate('2026-10-15')}
        isOptional
      />
    </VeliProvider>
  );
}
```
