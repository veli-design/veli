# DatePicker

`DatePicker` is the full input control most product teams will use. It combines the editable `DateField` experience with a `Calendar` popover for mouse, touch, and keyboard selection.

## Import

```tsx
import { DatePicker } from '@tradenetcorp/coral-ui/date-picker';
```

## Key Props

### Common

| Prop                  | Type                | Description                                                              |
| :-------------------- | :------------------ | :----------------------------------------------------------------------- |
| `label`               | `ReactNode`         | Visible label for the field.                                             |
| `description`         | `ReactNode`         | Helper text below the picker.                                            |
| `errorMessage`        | `ReactNode`         | Validation text shown when invalid.                                      |
| `isRequired`          | `boolean`           | Marks the picker as required.                                            |
| `isDisabled`          | `boolean`           | Disables both field editing and calendar trigger.                        |
| `isReadOnly`          | `boolean`           | Prevents edits but keeps the value visible.                              |
| `value`               | `DateValue \| null` | Controlled selected value.                                               |
| `defaultValue`        | `DateValue`         | Uncontrolled initial value.                                              |
| `onChange`            | `(value) => void`   | Called when the selected value changes.                                  |
| `name`                | `string`            | Submits the value in forms as an ISO string.                             |
| `calendarButtonLabel` | `string`            | Accessible name for the calendar trigger. Defaults to `"Open calendar"`. |

### Formatting

| Prop                      | Type                                      | Description                                          |
| :------------------------ | :---------------------------------------- | :--------------------------------------------------- |
| `granularity`             | `'day' \| 'hour' \| 'minute' \| 'second'` | Smallest displayed and editable segment.             |
| `hourCycle`               | `12 \| 24`                                | Forces 12-hour or 24-hour time display.              |
| `hideTimeZone`            | `boolean`                                 | Hides time zone text when using zoned values.        |
| `shouldForceLeadingZeros` | `boolean`                                 | Keeps numeric segments zero-padded.                  |
| `placeholderValue`        | `DateValue`                               | Sets placeholder shape and default calendar context. |

### Calendar Behavior

| Prop                  | Type                | Description                                                      |
| :-------------------- | :------------------ | :--------------------------------------------------------------- |
| `shouldCloseOnSelect` | `boolean`           | Controls whether the popover closes immediately after selection. |
| `minValue`            | `DateValue`         | Lowest selectable value.                                         |
| `maxValue`            | `DateValue`         | Highest selectable value.                                        |
| `isDateUnavailable`   | `(date) => boolean` | Marks dates as unavailable in the calendar.                      |

### Validation

| Prop        | Type                                         | Description                                    |
| :---------- | :------------------------------------------- | :--------------------------------------------- |
| `isInvalid` | `boolean`                                    | Forces invalid styling and error presentation. |
| `validate`  | `(value) => ValidationError \| true \| null` | Adds custom validation logic.                  |

All remaining supported React Aria `DatePicker` props can still be passed through this wrapper.
