# Spinner

<DocsTab id="overview">

Spinner is a ring of animated dots that shows something is loading when the wait is short and the shape of what is coming is not known, such as search results in a panel or the details in a Modal. It is announced as Loading unless you give it a more specific name. Pair it with Loading text when words help, use Skeleton when the content shape is known, and use Button isPending for an action a Button started.

## When to use

### Use a Spinner when

- Content or an action is pending and the layout needs an indeterminate indicator.
- A small region is waiting for content with no predictable shape, such as a Popover fetching help text or a Modal body loading an application's details.
- A busy control needs a compact indicator in its text colour. Use variant button.
- Nobody knows how long the wait will be or what shape the result has.

### Don't use a Spinner when

- The shape of the content is known. Compose Skeleton placeholders instead.
- A short label should explain the wait. Use Loading text, alone or beside the Spinner.
- A Button started the action. Set isLoading or isPending on the Button.
- Progress is known, such as an upload percentage or Checking documents, 2 of 5. Show progress as text, with a progress bar when the share of work is known. Drop zone shows upload progress for each file.
- Several parts of a view load together, such as every Card on a dashboard. Show one Spinner for the region, or Skeleton shapes for each part with one status message.

## Content guidelines

### Default name

Spinner has 1 built-in string, its accessible name: Loading, in Dhivehi ލޯޑުވަނީ, chosen by the VeliProvider language. Keep it when Loading is clear enough.

### Specific names

Override the name with aria-label when several parts of a page load or Loading is unclear. Name what is loading, not the component.

| Do                      | Don't                                                             |
| :---------------------- | :---------------------------------------------------------------- |
| Loading notifications   | Loading... (typed ellipsis)                                       |
| Loading payment history | Spinner (names the Spinner, not the wait)                         |
|                         | Please wait (says nothing about what is loading, and uses please) |

### Both languages

An override is not translated by Veli. Pass the English and the Dhivehi text yourself under language dv.

### No ellipsis

Write Loading payment history, not Loading followed by an ellipsis. The name is read aloud.

### Visible words

Spinner takes no children. Put visible words in a Loading text beside it.

- **Region loading**: centre the Spinner in the region that is waiting and keep the region's height, so the content doesn't push the page when it arrives.
- **With Loading text**: put the Spinner first, with aria-hidden, and let Loading text carry the name, so the wait is announced once.
- **Specific name**: when several parts of a page load, or Loading is unclear, override the name: aria-label Loading payment history.

## Behaviour

- **Animates until removed**: the dots loop every 1.6 seconds, or 1.92 seconds for variant button, for as long as the Spinner is on screen. Remove it as soon as content or an error arrives.
- **Timing**: wait about 150 to 300 ms before showing a Spinner and keep it for about 300 to 500 ms once shown, so fast responses never flash one.
- **When loading fails**: replace the Spinner with what went wrong and a Try again action.
- **Controls**: a Spinner alone doesn't disable the controls around it. Disable or set pending on anything that must wait.
- **Hold the space**: keep the region's height while the Spinner shows. A region that collapses to 24 and then grows moves everything below it.
- **Before hydration**: Spinner shows the static ring on the server and before the page is interactive, then animates unless reduced motion is on.
- **No children**: Spinner doesn't accept children. className can override its colour and size.

## Motion

| Variant | What it does                                                                                                                                               | Timing                                        | Reduced motion                                 |
| :------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------- | :--------------------------------------------- |
| default | 12 dots appear in turn around the ring. Each slides in from outside, holds, then shrinks towards the centre and fades, so a tail of dots circles the ring. | 1.6s loop, a new dot every 0.13s, never stops | A static ring of 12 dots at 65 percent opacity |
| button  | 8 dots light up in turn until the ring is full, then fade back to 15 percent in the same order.                                                            | 1.92s loop, never stops                       | A static ring of 8 dots at 65 percent opacity  |

Spinner follows changes to the reduced motion setting while it is on screen.

## Usage

<div className="preview mb-4 rounded-lg border p-4">
  <LoadingUsageDemo client:visible />
</div>

```tsx
<Spinner size="lg" aria-label="Loading notifications" />
<Spinner variant="button" aria-label="Saving" />
```

Pending buttons use the shared compact spinner by default. Button retains the original label and width while it is busy:

```tsx
<Button isPending={isSaving}>Save changes</Button>
```

The default spinner uses the general loading animation. The `button` variant uses the compact animation and inherits its text colour. Override the default spinner's colour or dimensions with `className`.

## Accessibility and reduced motion

`Spinner` provides `role="status"`. Give it a translated `aria-label`; its default is “Loading” in the current Veli language.

When a parent already announces progress, pass `aria-hidden="true"` to avoid duplicate announcements. Keep pending action controls disabled through their own component's pending state; a loading indicator alone does not block activation.

```tsx
<div role="status">
  <Spinner aria-hidden="true" />
  <span className="sr-only">Loading notifications…</span>
</div>
```

With reduced motion enabled, the spinner shows a static dotted ring.

## API Reference

| Prop        | Type                    | Default     | Description                                                    |
| :---------- | :---------------------- | :---------- | :------------------------------------------------------------- |
| `variant`   | `'default' \| 'button'` | `'default'` | Select the general or compact animation.                       |
| `size`      | `'sm' \| 'md' \| 'lg'`  | `'md'`      | Indicator size: 20, 24 or 32px with the default spacing scale. |
| `className` | `string`                | —           | Override colour, dimensions or layout.                         |

Supports standard HTML `span` attributes and a `ref` to the root span. `Spinner` does not accept children.

<DocsTab id="accessibility">

How the Spinner works with screen readers, focus, reduced motion and contrast. It is a status indicator, not a control.

## Screen readers

- Spinner has role status, not progressbar, and the name Loading by default (ލޯޑުވަނީ under language dv). Give it a translated aria-label when Loading is not enough.
- The dots are hidden from assistive technology.
- Pass aria-hidden when a parent live region already announces the progress, or when Loading text beside it carries the name. With aria-hidden, the Spinner drops its role and name.
- Don't rely on a newly added Spinner alone. Keep one role status region on the page from load, change its text when the wait starts and ends, and test it with NVDA, VoiceOver and TalkBack.
- Several Spinners each named Loading are announced one after another. Use one for the region.
- Inside a pending Button, Veli wraps a button-variant Spinner, hidden with aria-hidden, in a progressbar named Loading (ލޯޑުވަނީ in Dhivehi).

## Focus

Spinner is not focusable and has no keyboard interaction. Focus stays on the control that started the wait.

## Reduced motion

When the user prefers reduced motion, the Spinner shows a static dotted ring at 65 percent opacity. It switches if the setting changes while it is on screen. Nothing extra is needed from you.

## Contrast

The dots are a control part and need 3:1 against the surface, in Light and Dark separately. Check them on tinted or dark surfaces; the reduced motion ring draws them at 65 percent opacity.

## Right to left

Set the language with VeliProvider (language dv) and the default name becomes ލޯޑުވަނީ. The Spinner doesn't mirror. Pass a Dhivehi aria-label yourself when you override the name.
