# Tabs

Use Tabs for switching between related panels in a page section. Pass an `items` array with at least two tabs. Collapse extras with `overflowItems`, or pass `href` on an item for route-driven navigation.

## Import

```tsx
import { Tabs } from '@veli-design/react/tabs';
```

## Usage

<div className="preview mb-4 rounded-lg border p-4">
  <TabsUsageDemo client:visible />
</div>

```tsx
const items = [
  { id: 'overview', label: 'Overview', panel: 'Summary content.' },
  { id: 'services', label: 'Services', panel: 'Service list.' },
  { id: 'pricing', label: 'Pricing', panel: 'Fees and schedules.' },
];

<Tabs listAriaLabel="Service sections" items={items} />;
```

Size with `sm`, `md`, or `lg`. Use `leading` and `trailing` for icons or badges. The underline hugs the tab group; when tabs are wider than the container, the bar scrolls horizontally. Pass `tabListClassName="w-full"` for a full-width underline.

## Overflow

Pass additional tabs as `overflowItems` to collapse them behind a localized More menu.

<div className="preview mb-4 rounded-lg border p-4">
  <TabsOverflowDemo client:visible />
</div>

```tsx
<Tabs
  listAriaLabel="Workspace sections"
  items={items}
  overflowItems={[
    { id: 'billing', label: 'Billing', panel: 'Invoices.' },
    { id: 'integrations', label: 'Integrations', panel: 'Connected apps.' },
  ]}
/>
```

## Navigation

Pass `href` on an item to render that tab as a link. Drive selection from the current route and leave page content outside Tabs. When any item has an `href`, Tabs defaults `keyboardActivation` to `'manual'`. Wire client-side navigation through [`VeliProvider`](/docs/components/provider/) `navigate`, or a per-item `render` prop for framework `Link` components.

```tsx
<Tabs
  listAriaLabel="Team sections"
  selectedKey={pathname}
  onSelectionChange={() => {}}
  items={[
    { id: '/team/overview', label: 'Overview', href: '/team/overview' },
    { id: '/team/members', label: 'Members', href: '/team/members' },
  ]}
/>
```

Omit `panel` for route-driven tabs; Tabs still renders a visually hidden panel so `aria-controls` resolves.

## API Reference

Tabs is built on React Aria [`Tabs`](https://react-spectrum.adobe.com/react-aria/Tabs.html). Props below follow that stack.

### Tabs

Veli-specific props for the composed control.

| Prop               | Type                      | Default  | Description                                                            |
| :----------------- | :------------------------ | :------- | :--------------------------------------------------------------------- |
| `items`            | `[TabsItem, TabsItem, …]` | -        | Tabs to show. At least two.                                            |
| `overflowItems`    | `TabsItem[]`              | -        | Additional tabs collapsed into the More menu.                          |
| `size`             | `'sm' \| 'md' \| 'lg'`    | `'sm'`   | Tab padding and label typography.                                      |
| `listAriaLabel`    | `string`                  | `'Tabs'` | Accessible name for the tab list.                                      |
| `tabListClassName` | `string`                  | -        | Class on the underline bar. Use `"w-full"` for a full-width underline. |
| `tabClassName`     | `string`                  | -        | Class merged onto each visible tab.                                    |
| `panelClassName`   | `string`                  | -        | Class merged onto each visible panel.                                  |
| `className`        | `string`                  | -        | Layout class on the root (width, margin, flex/grid).                   |

### React Aria Tabs

React Aria’s headless [`Tabs`](https://react-spectrum.adobe.com/react-aria/Tabs.html#props). These props pass through. The React Aria docs cover the rest, except the exclusions below.

| Prop                 | Type                         | Default                | Description                                                |
| :------------------- | :--------------------------- | :--------------------- | :--------------------------------------------------------- |
| `selectedKey`        | `Key`                        | -                      | Controlled selected tab.                                   |
| `defaultSelectedKey` | `Key`                        | first enabled          | Uncontrolled initial tab.                                  |
| `onSelectionChange`  | `(key: Key) => void`         | -                      | Called when the active tab changes.                        |
| `keyboardActivation` | `'automatic' \| 'manual'`    | `'manual'` with `href` | When to select on focus.                                   |
| `isDisabled`         | `boolean`                    | `false`                | Disables the whole tab list.                               |
| `disabledKeys`       | `Iterable<Key>`              | -                      | Keys of tabs to disable. Prefer `isDisabled` on each item. |
| `orientation`        | `'horizontal' \| 'vertical'` | `'horizontal'`         | Tab list orientation.                                      |

Not forwarded from React Aria `Tabs`:

| Prop        | Why                                                |
| :---------- | :------------------------------------------------- |
| `children`  | Replaced by Veli’s `items` / `overflowItems`.      |
| `style`     | Not supported.                                     |
| `className` | Replaced by Veli’s layout `className` on the root. |

### TabsItem

| Prop         | Type               | Description                                         |
| :----------- | :----------------- | :-------------------------------------------------- |
| `id`         | `string \| number` | Stable tab key.                                     |
| `label`      | `ReactNode`        | Visible tab label.                                  |
| `panel`      | `ReactNode`        | Optional panel content. Omit for route-driven tabs. |
| `leading`    | `ReactNode`        | Content before the label.                           |
| `trailing`   | `ReactNode`        | Content after the label.                            |
| `isDisabled` | `boolean`          | Prevents selection.                                 |
| `href`       | `string`           | Renders the tab as a link.                          |
| `render`     | `RenderProps`      | Escape hatch for framework `Link` components.       |

Link DOM props (`target`, `rel`, `hrefLang`, `download`, `ping`, `referrerPolicy`, `routerOptions`) are also accepted on each item. `overflowItems` uses the same shape; panels still come from those items.

`TabsOverflow` is also exported for advanced composition inside an active React Aria tab list. Prefer `overflowItems` on `Tabs`.

## Accessibility

- Provide `listAriaLabel` so the tab list has an accessible name.
- Arrow keys move focus between visible tabs. Home and End jump to the first and last enabled tab.
- With automatic activation, focus also selects the tab. Link tabs default to manual activation.
- Disabled tabs are skipped. Overflow tabs are selected from the More menu.

## RTL and Language

Tabs inherit direction and language from `VeliProvider`. On `lang="dv"`, the overflow trigger label becomes `އިތުރު` and labels use the Dhivehi baseline adjustment. In RTL, the tab row, indicator, and More caret follow `dir`. Pass localized `label` and `panel` content on each item.
