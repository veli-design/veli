# Button

The Button component provides an accessible, keyboard-navigable button with multiple variants and sizes.

## Import

```tsx
import { Button } from '@tradenetcorp/coral-ui/button';
```

import { Button } from '@tradenetcorp/coral-ui/button';

## Usage

<div className="preview p-4 border rounded-lg bg-surface-100 mb-4">
  <Button client:visible>Click me</Button>
</div>

```tsx
<Button>Click me</Button>
```

## Props

- `variant`: `'primary' | 'secondary' | 'outline' | 'ghost'` (default: `'primary'`)
- `size`: `'sm' | 'md' | 'lg'` (default: `'md'`)
- All props from React Aria's `Button` component
