# Button

The Button component provides an accessible, keyboard-navigable button with multiple intents, appearances, and sizes.

## Import

```tsx

import { Plus, ArrowRight } from 'phosphor-react';
```

## Intent And Appearance Matrix

The button supports four intents (`primary`, `secondary`, `danger`, `accent`) and three appearances. Accent is fill-only.

## Icons

To maintain design consistency, icons should follow these size guidelines:

- **XL Buttons**: 20px
- **LG Buttons**: 20px
- **MD/SM Buttons**: 16px
- **XS Buttons**: 12px

<div className="preview p-4 border border-base-subtle rounded-lg bg-surface-raised mb-4 flex gap-4 flex-wrap items-center">
  <ButtonIconsDemo client:visible />
</div>

```tsx
// Example of correctly sized icons
<Button size="xl"><Plus size={20} /> Add item</Button>
<Button size="lg"><Plus size={20} /> Add item</Button>
<Button size="md"><Plus size={16} /> Add item</Button>
<Button size="xs"><Plus size={12} /> Add item</Button>
```

## Icon-Only

Use `iconOnly` when the button should render as a square icon action while keeping the same intent, appearance, and size behavior as the standard button.

Always provide an accessible label with `aria-label` or `aria-labelledby` when there is no visible text. In development, `iconOnly` buttons without a label fail fast.

<div className="preview p-4 border border-base-subtle rounded-lg bg-surface-raised mb-4 flex gap-4 flex-wrap items-center">
  <ButtonIconOnlyDemo client:visible />
</div>

```tsx
<Button size="md" iconOnly aria-label="Delete item">
  <Trash size={16} />
</Button>
```

## Loading State

When `isLoading` is true, the button is disabled, marked busy, and displays a spinner while maintaining its dimensions. If a loading button has no visible children, provide `aria-label` or `aria-labelledby` so it is not announced as an unnamed control.

<div className="preview p-4 border border-base-subtle rounded-lg bg-surface-raised mb-4 flex gap-4 items-center">
  <ButtonLoadingDemo client:visible />
</div>

```tsx
<Button isLoading>Processing...</Button>
<Button isLoading aria-label="Saving" />
```

## Props

| Prop         | Type                                               | Default     | Description                                                                                                          |
| :----------- | :------------------------------------------------- | :---------- | :------------------------------------------------------------------------------------------------------------------- |
| `intent`     | `'primary' \| 'secondary' \| 'danger' \| 'accent'` | `'primary'` | The semantic visual indication level of the button. Accent is fill-only.                                             |
| `appearance` | `'fill' \| 'transparent' \| 'ghost'`               | `'fill'`    | The surface treatment of the button.                                                                                 |
| `size`       | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`             | `'md'`      | The vertical scale of the button.                                                                                    |
| `iconOnly`   | `boolean`                                          | `false`     | Renders the button as a square icon action. Requires `aria-label` or `aria-labelledby`.                              |
| `isLoading`  | `boolean`                                          | `false`     | Shows a loading spinner, disables interaction, and sets `aria-busy`. Spinner-only usage requires an accessible name. |
| `isDisabled` | `boolean`                                          | `false`     | Standard disabled state.                                                                                             |

_Note: All other `react-aria-components` Button props are supported, excluding `className` and `style` overrides._
