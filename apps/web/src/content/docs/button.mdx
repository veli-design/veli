# Button

The Button component provides an accessible, keyboard-navigable button with multiple variants, styles, and sizes.

## Import

```tsx
import { Button } from '@tradenetcorp/coral-ui/button';
import { Plus, ArrowRight } from 'phosphor-react';
```

import { Button } from '@tradenetcorp/coral-ui/button';
import { Plus, ArrowRight, Trash, DownloadSimple } from 'phosphor-react';

## Usage

<div className="preview p-4 border rounded-lg bg-surface-100 mb-4">
  <Button client:visible>Click me</Button>
</div>

```tsx
<Button>Click me</Button>
```

## Icons

To maintain design consistency, icons should follow these size guidelines:
- **XL Buttons**: 24px
- **LG Buttons**: 20px
- **MD/SM Buttons**: 16px
- **XS Buttons**: 12px

## Loading State

When `isLoading` is true, the button is disabled and displays a spinner while maintaining its dimensions.

<div className="preview p-4 border rounded-lg bg-surface-100 mb-4 flex gap-4 items-center">
  <Button isLoading client:visible>Processing...</Button>
</div>

```tsx
<Button isLoading>Processing...</Button>
```

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `'primary' \| 'secondary' \| 'danger'` | `'primary'` | The visual category of the button. |
| `style` | `'fill' \| 'transparent' \| 'ghost'` | `'fill'` | The internal fill/border style. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | The vertical scale of the button. |
| `isLoading` | `boolean` | `false` | Shows a loading spinner and disables interaction. |
| `isDisabled` | `boolean` | `false` | Standard disabled state. |

*Note: All other `react-aria-components` Button props are supported, excluding `className` and `style` overrides.*
