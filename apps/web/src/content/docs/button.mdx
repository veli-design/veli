# Button

The Button component provides an accessible, keyboard-navigable button with multiple variants, styles, and sizes.

## Import

```tsx
import { Button } from '@tradenetcorp/coral-ui/button';
import { Plus, ArrowRight } from 'phosphor-react';
```

## Icons

To maintain design consistency, icons should follow these size guidelines:
- **XL Buttons**: 24px
- **LG Buttons**: 20px
- **MD/SM Buttons**: 16px
- **XS Buttons**: 12px

<div className="preview p-4 border rounded-lg bg-surface-100 mb-4 flex gap-4 flex-wrap items-center">
  <ButtonIconsDemo client:visible />
</div>

```tsx
// Example of correctly sized icons
<Button size="xl"><Plus size={24} /></Button>
<Button size="lg"><Plus size={20} /></Button>
<Button size="md"><Plus size={16} /></Button>
<Button size="xs"><Plus size={12} /></Button>
```

## Loading State

When `isLoading` is true, the button is disabled and displays a spinner while maintaining its dimensions.

<div className="preview p-4 border rounded-lg bg-surface-100 mb-4 flex gap-4 items-center">

```tsx

```

## Enhanced Styling

Use `treatment="seaglass"` to opt into the stylized treatment without changing the base button behavior.

<div className="preview p-4 border rounded-lg bg-surface-100 mb-4 flex gap-4 items-center flex-wrap">
  <ButtonSeaglassDemo client:visible />
</div>

```tsx
<Button variant="primary" style="fill" size="xl" treatment="seaglass">
  <Plus size={24} />
  Label
  <ArrowRight size={24} />
</Button>
```

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `'primary' \| 'secondary' \| 'danger'` | `'primary'` | The visual category of the button. |
| `style` | `'fill' \| 'transparent' \| 'ghost'` | `'fill'` | The internal fill/border style. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | The vertical scale of the button. |
| `treatment` | `'basic' \| 'seaglass'` | `'basic'` | Selects the visual rendering family without changing the semantic variant/style API. |
| `isLoading` | `boolean` | `false` | Shows a loading spinner and disables interaction. |
| `isDisabled` | `boolean` | `false` | Standard disabled state. |

*Note: All other `react-aria-components` Button props are supported, excluding `className` and `style` overrides.*
