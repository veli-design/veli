# Modal

The `Modal` component provides an accessible dialog surface with focus management, escape handling, and dismiss behavior powered by React Aria.

## Import

```tsx
import { Modal } from '@tradenetcorp/veli-ui/modal';
import { Button } from '@tradenetcorp/veli-ui/button';
```

## Usage

Click the trigger below to open a standard controlled modal with title, body, and footer actions.

<div className="preview p-4 border border-border-default-subtle rounded-lg bg-bg-surface-raised mb-4">
  <ModalBasicDemo client:visible />
</div>

```tsx
function Example() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <Button onPress={() => setIsOpen(true)}>Open modal</Button>

      <Modal
        isOpen={isOpen}
        onOpenChange={setIsOpen}
        title="Edit profile"
        footer={
          <>
            <Button intent="secondary" appearance="transparent" onPress={() => setIsOpen(false)}>
              Cancel
            </Button>
            <Button onPress={() => setIsOpen(false)}>Save changes</Button>
          </>
        }
      >
        <p>Update your profile details and save when done.</p>
      </Modal>
    </>
  );
}
```

## Sizes

The modal supports five size variants to fit different content density and workflow needs:

- `sm`
- `md`
- `lg`
- `xl`
- `full`

## Dismiss Behavior

For high-risk actions, you can disable outside-click and `Escape` dismissal.

<div className="preview p-4 border border-border-default-subtle rounded-lg bg-bg-surface-raised mb-4">
  <ModalDismissDemo client:visible />
</div>

```tsx
// Standard (dismissable)
<Modal isDismissable title="Edit profile"><p>Body content.</p></Modal>

// Locked modal for destructive actions
<Modal
  title="Confirm destructive action"
  isDismissable={false}
  isKeyboardDismissDisabled
  showCloseButton={false}
>
  <p>This action needs an explicit choice.</p>
</Modal>
```

## Composition

`Modal` is slot-based and library-friendly:

- `title`: heading area and default dialog label
- `children`: body content
- `footer`: actions section

Every modal needs one dialog name: use `title`, `aria-label`, or `aria-labelledby`. In development, unlabeled dialogs fail fast instead of rendering silently.

```tsx
<Modal
  title="Edit profile"
  footer={
    <>
      <Button intent="secondary" appearance="transparent">
        Cancel
      </Button>
      <Button>Save changes</Button>
    </>
  }
>
  <p>Body content goes here.</p>
</Modal>
```

## Props

| Prop                        | Type                                     | Default          | Description                                                                                    |
| :-------------------------- | :--------------------------------------- | :--------------- | :--------------------------------------------------------------------------------------------- |
| `size`                      | `'sm' \| 'md' \| 'lg' \| 'xl' \| 'full'` | `'md'`           | Width/height scale of the modal surface.                                                       |
| `title`                     | `ReactNode`                              | -                | Modal heading and dialog label. Required unless `aria-label` or `aria-labelledby` is provided. |
| `aria-label`                | `string`                                 | -                | Accessible dialog name for titleless compositions.                                             |
| `aria-labelledby`           | `string`                                 | -                | ID reference for an external dialog label.                                                     |
| `footer`                    | `ReactNode`                              | -                | Optional footer action area.                                                                   |
| `showCloseButton`           | `boolean`                                | `true`           | Shows/hides top-right close button.                                                            |
| `closeButtonLabel`          | `string`                                 | `'Close dialog'` | Accessible label for close button.                                                             |
| `isDismissable`             | `boolean`                                | `true`           | Allows click-outside dismissal.                                                                |
| `isKeyboardDismissDisabled` | `boolean`                                | `false`          | Disables `Escape` to close.                                                                    |
| `isOpen`                    | `boolean`                                | -                | Controlled open state.                                                                         |
| `defaultOpen`               | `boolean`                                | -                | Uncontrolled initial open state.                                                               |
| `onOpenChange`              | `(isOpen: boolean) => void`              | -                | Open state change callback.                                                                    |
| `className`                 | `string`                                 | -                | Class overrides for modal surface.                                                             |
| `contentClassName`          | `string`                                 | -                | Class overrides for content area.                                                              |
| `overlayClassName`          | `string`                                 | -                | Class overrides for backdrop container.                                                        |

_Note: The component also supports remaining `react-aria-components` `ModalOverlay` props (except replacing `children` with this API)._
