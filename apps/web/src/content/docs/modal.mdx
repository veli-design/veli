# Modal

Use Modal for focused work that should block the rest of the page: confirmations, short forms, and destructive choices.

## Import

```tsx
import { Modal } from '@tradenetcorp/veli-ui/modal';
import { Button } from '@tradenetcorp/veli-ui/button';
```

## Usage

<div className="preview mb-4 rounded-lg border p-4">
  <ModalUsageDemo client:visible />
</div>

```tsx
<Modal.Trigger>
  <Button>Open modal</Button>
  <Modal>
    <Modal.Header>
      <Modal.Title>Edit profile</Modal.Title>
      <Modal.CloseButton />
    </Modal.Header>
    <Modal.Content>
      <p>Update your profile details and save when done.</p>
    </Modal.Content>
    <Modal.Footer>
      <Button slot="close" intent="secondary" appearance="transparent">
        Cancel
      </Button>
      <Button slot="close">Save changes</Button>
    </Modal.Footer>
  </Modal>
</Modal.Trigger>
```

`Modal.Trigger` owns open state and restores focus to the opener. Use controlled `isOpen` / `onOpenChange` when routing or async guards manage visibility.

## Sizes

`xs` is for confirmations without a description divider. Larger sizes share the same header, content, and footer chrome.

<div className="preview mb-4 rounded-lg border p-4">

```tsx
<Modal size="lg">...</Modal>
<Modal size="xl">...</Modal>
<Modal size="full">...</Modal>
```

## Dismiss

Pass `isDismissable={false}` and `isKeyboardDismissDisabled` when the user must pick an explicit action. Omit `Modal.CloseButton` for the same flows.

<div className="preview mb-4 rounded-lg border p-4">
  <ModalDismissDemo client:visible />
</div>

```tsx
<Modal isDismissable={false} isKeyboardDismissDisabled>
  <Modal.Header>
    <Modal.Title>Confirm destructive action</Modal.Title>
  </Modal.Header>
  <Modal.Content>
    <p>Outside click and Escape are disabled. Choose an explicit action.</p>
  </Modal.Content>
  <Modal.Footer>
    <Button slot="close" intent="secondary" appearance="transparent">
      Cancel
    </Button>
    <Button slot="close" intent="danger">
      Delete
    </Button>
  </Modal.Footer>
</Modal>
```

## Footer Layout

`Modal.Footer` lays out start- and end-edge action groups with `justify-between`. Place each group as a separate child.

<div className="preview mb-4 rounded-lg border p-4">
  <ModalFooterDemo client:visible />
</div>

```tsx
<Modal.Footer>
  <div className="flex gap-2">
    <Button slot="close" intent="secondary" appearance="transparent">
      View history
    </Button>
  </div>
  <div className="flex gap-2">
    <Button slot="close" intent="secondary" appearance="transparent">
      Cancel
    </Button>
    <Button slot="close">Save changes</Button>
  </div>
</Modal.Footer>
```

## API Reference

Modal is a Veli compound dialog on React Aria [`Modal`](https://react-spectrum.adobe.com/react-aria/Modal.html) / [`Dialog`](https://react-spectrum.adobe.com/react-aria/Dialog.html). Props below follow that stack.

### Modal

Veli-specific props for the dialog surface.

| Prop               | Type                                             | Default | Description                                    |
| :----------------- | :----------------------------------------------- | :------ | :--------------------------------------------- |
| `size`             | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| 'full'` | `'md'`  | Max width of the panel.                        |
| `aria-label`       | `string`                                         | -       | Accessible name when `Modal.Title` is omitted. |
| `aria-labelledby`  | `string`                                         | -       | ID of an external accessible name.             |
| `overlayClassName` | `string`                                         | -       | Class on the backdrop overlay.                 |
| `className`        | `string`                                         | -       | Layout class on the modal panel.               |

### ModalOverlay

React Aria’s headless [`ModalOverlay`](https://react-spectrum.adobe.com/react-aria/Modal.html#modaloverlay). These props pass through. The React Aria docs cover the rest, except the exclusions below.

| Prop                        | Type                        | Default | Description                      |
| :-------------------------- | :-------------------------- | :------ | :------------------------------- |
| `isOpen`                    | `boolean`                   | -       | Controlled open state.           |
| `defaultOpen`               | `boolean`                   | -       | Uncontrolled initial open state. |
| `onOpenChange`              | `(isOpen: boolean) => void` | -       | Called when open state changes.  |
| `isDismissable`             | `boolean`                   | `true`  | Allows click-outside dismissal.  |
| `isKeyboardDismissDisabled` | `boolean`                   | `false` | Disables Escape to close.        |

Not forwarded from `ModalOverlay`:

| Prop        | Why                                                |
| :---------- | :------------------------------------------------- |
| `children`  | Veli owns the compound composition.                |
| `className` | Replaced by Veli `className` / `overlayClassName`. |

### Composition

Assemble the dialog with `Modal.Trigger`, `Modal.Header`, `Modal.Title`, `Modal.Description`, `Modal.CloseButton`, `Modal.Content`, and `Modal.Footer`.

| Part                | Notes                                                              |
| :------------------ | :----------------------------------------------------------------- |
| `Modal.Trigger`     | Wraps the opener and modal; manages open state and focus return.   |
| `Modal.Title`       | Dialog heading and accessible name.                                |
| `Modal.Description` | Optional subtitle; shows the header divider when present.          |
| `Modal.CloseButton` | Optional dismiss control. Default `aria-label` is localized.       |
| `Modal.Footer`      | Action row. Place start- and end-edge groups as separate children. |

### Modal.CloseButton

| Prop         | Type     | Default              | Description                     |
| :----------- | :------- | :------------------- | :------------------------------ |
| `aria-label` | `string` | Localized Close name | Accessible name for the button. |

## Accessibility

- Provide one dialog name: `Modal.Title`, `aria-label`, or `aria-labelledby`.
- Focus is trapped while open and restored to the trigger on close when using `Modal.Trigger`.
- Escape and outside click dismiss when `isDismissable` allows it.

## RTL and Language

The overlay inherits `lang` and `dir` from `VeliProvider`. Title, body, and footer alignment follow `dir`. On `lang="dv"`, `Modal.CloseButton` defaults to `ލައްޕާ`.
