# Popover

Show interactive content beside the control that opened it — filters, quick settings, or onboarding steps. Compose a pressable trigger and `Popover` inside `PopoverTrigger`, then put a `PopoverDialog` inside the popover. Use [Tooltip](/docs/components/tooltip/) for brief, non-interactive help, [Menu](/docs/components/menu/) for a list of actions, and [Modal](/docs/components/modal/) for blocking tasks that are not tied to a trigger.

## Import

```tsx
import {
  Popover,
  PopoverContent,
  PopoverDialog,
  PopoverFooter,
  PopoverHeader,
  PopoverTrigger,
} from '@veli-design/react/popover';
import { Button } from '@veli-design/react/button';
```

## Usage

<div className="preview mb-4 rounded-lg border p-4">
  <PopoverUsageDemo client:visible />
</div>

```tsx
<PopoverTrigger>
  <Button intent="secondary">Account</Button>
  <Popover placement="bottom" className="w-[274px]">
    <PopoverDialog>
      {({ close }) => (
        <>
          <PopoverHeader title="Account" icon={<UserIcon aria-hidden />} onClose={close} />
          <PopoverContent>
            <p className="type-body-sm-regular">Signed in as Aishath Ali.</p>
          </PopoverContent>
          <PopoverFooter label="Step 1 of 2">
            <Button intent="primary" size="xs" onPress={close}>
              Next
            </Button>
          </PopoverFooter>
        </>
      )}
    </PopoverDialog>
  </Popover>
</PopoverTrigger>
```

`PopoverTrigger` owns open state and restores focus to the opener. Use controlled `isOpen` / `onOpenChange` when routing or async guards manage visibility. Size the surface with `className` — Figma draws it 274px wide.

## Intents

`tertiary` is the default raised surface. `primary` uses the brand surface and `secondary` the inverse surface. Header, footer, close button, and arrow follow the intent.

<div className="preview mb-4 rounded-lg border p-4">

</div>

```tsx
<Popover intent="primary">
  …
  <PopoverFooter label="Label">
    <Button intent="secondary" size="xs">
      Next
    </Button>
  </PopoverFooter>
</Popover>
```

Pair footer actions with the surface: `secondary` buttons on `primary` popovers, and `primary` buttons on `secondary` and `tertiary` popovers.

## API Reference

Popover is a Veli surface on React Aria [`DialogTrigger`](https://react-spectrum.adobe.com/react-aria/DialogTrigger.html), [`Popover`](https://react-spectrum.adobe.com/react-aria/Popover.html), and [`Dialog`](https://react-spectrum.adobe.com/react-aria/Dialog.html). Props below follow that stack.

### Popover

Veli-specific props for the positioned surface.

| Prop        | Type                                     | Default       | Description                                                  |
| :---------- | :--------------------------------------- | :------------ | :----------------------------------------------------------- |
| `intent`    | `'primary' \| 'secondary' \| 'tertiary'` | `'tertiary'`  | Surface treatment for the popover and its parts.             |
| `showArrow` | `boolean`                                | `true`        | Renders the directional arrow.                               |
| `className` | `string` or render function              | -             | Classes on the positioned root, such as width or max height. |
| `lang`      | `string`                                 | from provider | Language of the portaled surface.                            |
| `dir`       | `string`                                 | from provider | Direction of the portaled surface.                           |
| `children`  | `ReactNode`                              | -             | Usually a `PopoverDialog`.                                   |

### React Aria Popover

React Aria’s headless [`Popover`](https://react-spectrum.adobe.com/react-aria/Popover.html#popover). These props pass through, with Veli defaults for `offset` and `arrowBoundaryOffset`. The React Aria docs cover the rest.

| Prop                        | Type                         | Default               | Description                                   |
| :-------------------------- | :--------------------------- | :-------------------- | :-------------------------------------------- |
| `placement`                 | `Placement`                  | `'bottom'`            | Preferred physical or logical side/alignment. |
| `offset`                    | `number`                     | `12` / `8`            | Gap from the trigger with or without arrow.   |
| `crossOffset`               | `number`                     | `0`                   | Offset along the other axis.                  |
| `arrowBoundaryOffset`       | `number`                     | `20`                  | Minimum arrow inset from the surface edge.    |
| `shouldFlip`                | `boolean`                    | `true`                | Flip when the preferred side lacks space.     |
| `containerPadding`          | `number`                     | `12`                  | Minimum distance from the container boundary. |
| `isNonModal`                | `boolean`                    | `false`               | Allow interaction outside while open.         |
| `isKeyboardDismissDisabled` | `boolean`                    | `false`               | Prevent Escape from closing.                  |
| `triggerRef`                | `RefObject<Element \| null>` | from `PopoverTrigger` | Anchor for standalone positioning.            |

### PopoverTrigger

React Aria’s headless [`DialogTrigger`](https://react-spectrum.adobe.com/react-aria/DialogTrigger.html). Veli forwards its props unchanged.

| Prop           | Type                        | Default | Description                                    |
| :------------- | :-------------------------- | :------ | :--------------------------------------------- |
| `isOpen`       | `boolean`                   | -       | Controlled open state.                         |
| `defaultOpen`  | `boolean`                   | `false` | Uncontrolled initial open state.               |
| `onOpenChange` | `(isOpen: boolean) => void` | -       | Called when the open state changes.            |
| `children`     | `ReactNode`                 | -       | A pressable trigger followed by the `Popover`. |

### Composition

Assemble the dialog with `PopoverDialog`, `PopoverHeader`, `PopoverContent`, and `PopoverFooter`.

| Part             | Notes                                                                               |
| :--------------- | :---------------------------------------------------------------------------------- |
| `PopoverDialog`  | Dialog semantics and focus. `children` may be a function that receives `{ close }`. |
| `PopoverHeader`  | Optional icon, title heading, close button, and divider.                            |
| `PopoverContent` | Padded body that grows and can scroll.                                              |
| `PopoverFooter`  | Optional divider, caption label, and end-aligned actions.                           |

### PopoverHeader

| Prop               | Type                         | Default   | Description                                                  |
| :----------------- | :--------------------------- | :-------- | :----------------------------------------------------------- |
| `title`            | `ReactNode`                  | -         | Dialog heading; names the `PopoverDialog`.                   |
| `titleLevel`       | `1 \| 2 \| 3 \| 4 \| 5 \| 6` | `2`       | Heading level for `title`.                                   |
| `icon`             | `ReactNode`                  | -         | Decorative leading icon.                                     |
| `onClose`          | `() => void`                 | -         | Shows the close button; usually the `close` render argument. |
| `closeButtonLabel` | `string`                     | Localized | Accessible name for the close button.                        |
| `showDivider`      | `boolean`                    | `true`    | Show the divider below the header.                           |
| `children`         | `ReactNode`                  | -         | Replaces the icon and title; label the dialog yourself.      |

Native `<div>` attributes such as `id`, `className`, and `data-*` are forwarded.

### PopoverContent

| Prop       | Type        | Default | Description   |
| :--------- | :---------- | :------ | :------------ |
| `children` | `ReactNode` | -       | Body content. |

Native `<div>` attributes are forwarded.

### PopoverFooter

| Prop          | Type        | Default | Description                                 |
| :------------ | :---------- | :------ | :------------------------------------------ |
| `label`       | `ReactNode` | -       | Caption text at the start of the footer.    |
| `showDivider` | `boolean`   | `true`  | Show the divider above the footer.          |
| `children`    | `ReactNode` | -       | Actions aligned to the end with an 8px gap. |

Native `<div>` attributes are forwarded.

## Accessibility

- Provide one dialog name: `PopoverHeader` `title`, or `aria-label` / `aria-labelledby` on `PopoverDialog`.
- Focus moves into the dialog on open and returns to the trigger on close. Escape dismisses unless `isKeyboardDismissDisabled` is set.
- Icon-only triggers need an `aria-label`. Header icons and dividers are decorative.
- Entry and exit fade, scale, and slide from the trigger. Reduced motion keeps the fade and removes the movement.

## RTL and Language

The overlay inherits `lang` and `dir` from `VeliProvider`. Logical placements, the arrow side, and header and footer alignment follow `dir`. On `lang="dv"`, the default close button label is `ޕޮޕްއޯވަރ ބަންދުކުރައްވާ`.
