# PasswordInput

The PasswordInput component extends the Input field shell for credential entry. It adds a visibility toggle, an optional live requirement checklist, success styling, and inline feedback for password match or mismatch messaging.

## Import

```tsx
import { PasswordInput } from '@tradenetcorp/veli-ui/password-input';
```

## Usage

<div className="preview mb-4 rounded-lg border p-4">
  <PasswordInputUsageDemo client:visible />
</div>

```tsx
<PasswordInput
  label="Password"
  placeholder="Enter a password"
  description="Use at least 8 characters."
/>
```

## Requirement checklist

Pass `requirements` to render the built-in checklist, which updates live as the user types. Pass an array of `PasswordRequirement` objects to customize the rules.

<div className="preview mb-4 rounded-lg border p-4">
  <PasswordInputRequirementsDemo client:visible />
</div>

```tsx
<PasswordInput label="Create password" requirements showRequirementsWhenEmpty />
```

The helpers `getDefaultPasswordRequirements`, `resolvePasswordRequirements`, and `arePasswordRequirementsMet` are exported alongside the component for validating values outside the field.

## Props

| Prop                             | Type                               | Default | Description                                                       |
| :------------------------------- | :--------------------------------- | :------ | :---------------------------------------------------------------- |
| `label`                          | `ReactNode`                        | -       | Visible label content.                                            |
| `description`                    | `ReactNode`                        | -       | Helper text shown beneath the field when not invalid.             |
| `errorMessage`                   | `ReactNode`                        | -       | Validation content shown beneath the field when `isInvalid`.      |
| `requirements`                   | `PasswordRequirement[] \| boolean` | -       | Renders the requirement checklist; `true` uses the default rules. |
| `showRequirementsWhenEmpty`      | `boolean`                          | `false` | Shows the checklist before the user types.                        |
| `isSuccess`                      | `boolean`                          | `false` | Applies the success field styling.                                |
| `feedbackMessage`                | `ReactNode`                        | -       | Inline feedback below the field, e.g. password match messages.    |
| `feedbackTone`                   | `'success' \| 'danger'`            | -       | Tone of the inline feedback message.                              |
| `showVisibilityToggle`           | `boolean`                          | `true`  | Shows the reveal/hide toggle button.                              |
| `isRevealed` / `defaultRevealed` | `boolean`                          | -       | Controlled / uncontrolled visibility of the entered value.        |
| `onRevealedChange`               | `(isRevealed: boolean) => void`    | -       | Called when the visibility toggle changes.                        |
| `className`                      | `string`                           | -       | Layout-only class override merged onto the root element.          |

All other `react-aria-components` `TextField` props are supported, excluding `style`, `type`, and direct child composition.

In RTL layouts the field UI stays RTL while the entered value renders LTR with English typography metrics, so passwords keep their intended character order.
