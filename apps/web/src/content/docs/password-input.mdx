# PasswordInput

Use PasswordInput for credentials and new-password setup. It follows the same label, helper, and validation pattern as [Input](/docs/input/), and adds a visibility toggle, an optional live requirement checklist, and inline match or mismatch feedback.

## Import

```tsx
import { PasswordInput } from '@tradenetcorp/veli-ui/password-input';
```

## Usage

<div className="preview mb-4 rounded-lg border p-4">
  <PasswordInputUsageDemo client:visible />
</div>

```tsx
<PasswordInput
  label="Password"
  placeholder="Enter a password"
  description="Use at least 8 characters."
/>
```

The field includes a visibility toggle by default. Pass `showVisibilityToggle={false}` to hide it. The entered value always renders left-to-right with English typography metrics, including inside an RTL layout.

## Appearances

`default` uses the underline shell. `outline` draws a bordered field. Size the field with `sm`, `md`, or `lg`.

<div className="preview mb-4 rounded-lg border p-4">
  <PasswordInputAppearancesDemo client:visible />
</div>

```tsx
<PasswordInput label="Default" placeholder="Enter a password" />
<PasswordInput appearance="outline" label="Outline" placeholder="Enter a password" />
```

## Requirement checklist

Pass `requirements` to render the built-in checklist, which updates live as the user types. Pass `true` for the default rules, or an array of `PasswordRequirement` objects to customize them. The checklist stays hidden on an empty field unless `showRequirementsWhenEmpty` is set. When every rule is met, the field applies success styling.

<div className="preview mb-4 rounded-lg border p-4">
  <PasswordInputRequirementsDemo client:visible />
</div>

```tsx
<PasswordInput label="Create password" requirements showRequirementsWhenEmpty />
```

The helpers `getDefaultPasswordRequirements`, `resolvePasswordRequirements`, and `arePasswordRequirementsMet` are exported alongside the component for validating values outside the field.

## Match and mismatch

Use `feedbackMessage` with `feedbackTone` for confirm-password copy. `feedbackTone="success"` (or `isSuccess`) applies the success shell. A checklist or feedback row replaces the helper and error text.

<div className="preview mb-4 rounded-lg border p-4">
  <PasswordInputMatchDemo client:visible />
</div>

```tsx
<PasswordInput
  label="Confirm password"
  feedbackMessage="Password match"
  feedbackTone="success"
  isSuccess
/>
```

## Validation

When `isInvalid` is set, `errorMessage` replaces the helper text. Invalid fields also replace the visibility toggle with a decorative status icon.

<div className="preview mb-4 rounded-lg border p-4">
  <PasswordInputValidationDemo client:visible />
</div>

```tsx
<PasswordInput label="Password" isInvalid errorMessage="This field needs attention." />
```

## API Reference

PasswordInput is a Veli field on React Aria [`TextField`](https://react-spectrum.adobe.com/react-aria/TextField.html), which wraps a native `<input>`. Props below follow that stack.

### PasswordInput

Veli-specific props for the composed field.

| Prop                        | Type                               | Default          | Description                                           |
| :-------------------------- | :--------------------------------- | :--------------- | :---------------------------------------------------- |
| `appearance`                | `'default' \| 'outline'`           | `'default'`      | Underline or bordered field.                          |
| `size`                      | `'sm' \| 'md' \| 'lg'`             | `'md'`           | Field size.                                           |
| `label`                     | `ReactNode`                        | -                | Visible label.                                        |
| `labelSupplementary`        | `ReactNode`                        | -                | Inline label helper, e.g. `Optional`.                 |
| `infoTooltip`               | `ReactNode`                        | -                | Content for the header info tooltip.                  |
| `infoTooltipAriaLabel`      | `string`                           | Localized string | Accessible name for the info tooltip trigger.         |
| `labelIcon`                 | `ReactNode`                        | -                | Small icon after the label.                           |
| `action`                    | `ReactNode`                        | -                | Right-aligned header content.                         |
| `description`               | `ReactNode`                        | -                | Helper text beneath the field.                        |
| `errorMessage`              | `ReactNode`                        | -                | Error text shown when `isInvalid`.                    |
| `showRequiredIndicator`     | `boolean`                          | `true`           | Shows the required asterisk when `isRequired`.        |
| `startAddon`                | `ReactNode`                        | -                | Leading inset accessory inside the shell.             |
| `startContent`              | `ReactNode`                        | -                | Leading inline content inside the shell.              |

| `showRequirementsWhenEmpty` | `boolean`                          | `false`          | Shows the checklist before the user types.            |
| `isSuccess`                 | `boolean`                          | `false`          | Applies the success field styling.                    |
| `feedbackMessage`           | `ReactNode`                        | -                | Inline match or mismatch copy beneath the field.      |
| `feedbackTone`              | `'success' \| 'danger'`            | `'danger'`       | Tone of `feedbackMessage`.                            |
| `showVisibilityToggle`      | `boolean`                          | `true`           | Shows the reveal/hide toggle. Off while `isInvalid`.  |
| `defaultRevealed`           | `boolean`                          | `false`          | Uncontrolled initial reveal state.                    |
| `isRevealed`                | `boolean`                          | -                | Controlled reveal state.                              |
| `onRevealedChange`          | `(isRevealed: boolean) => void`    | -                | Called when the visibility toggle changes.            |
| `className`                 | `string`                           | -                | Layout class on the root (width, margin, flex/grid).  |
| `ref`                       | `Ref<HTMLInputElement>`            | -                | Forwarded to the inner input.                         |

### TextField

React Aria’s headless [`TextField`](https://react-spectrum.adobe.com/react-aria/TextField.html#props). These props pass through. The React Aria docs cover the rest, except the exclusions below.

| Prop           | Type                      | Default | Description                    |
| :------------- | :------------------------ | :------ | :----------------------------- |
| `value`        | `string`                  | -       | Controlled value.              |
| `defaultValue` | `string`                  | -       | Uncontrolled initial value.    |
| `onChange`     | `(value: string) => void` | -       | Called when the value changes. |
| `isDisabled`   | `boolean`                 | `false` | Disables the field.            |
| `isInvalid`    | `boolean`                 | `false` | Marks the field invalid.       |
| `isReadOnly`   | `boolean`                 | `false` | Prevents editing.              |
| `isRequired`   | `boolean`                 | `false` | Marks the field required.      |
| `name`         | `string`                  | -       | Native form field name.        |
| `validate`     | `function`                | -       | Custom validation.             |
| `autoFocus`    | `boolean`                 | `false` | Focuses the field on mount.    |

Not forwarded from `TextField`:

| Prop         | Why                                                                            |
| :----------- | :----------------------------------------------------------------------------- |
| `children`   | Veli owns the field composition.                                               |
| `style`      | Not supported.                                                                 |
| `className`  | Replaced by Veli’s layout `className` on the root.                             |
| `spellCheck` | Omitted from `TextField` and applied to the inner input instead.               |
| `type`       | Owned by the reveal state (`password` or `text`). Do not pass a native `type`. |

### Native input

The native `<input>` that React Aria wraps. These attributes are applied to that element. `autoComplete` defaults to `current-password`.

| Prop             | Type      | Description                       |
| :--------------- | :-------- | :-------------------------------- |
| `placeholder`    | `string`  | Placeholder for an empty field.   |
| `maxLength`      | `number`  | Maximum length.                   |
| `minLength`      | `number`  | Minimum length.                   |
| `pattern`        | `string`  | Native validation pattern.        |
| `autoComplete`   | `string`  | Browser autocomplete token.       |
| `autoCapitalize` | `string`  | Virtual-keyboard capitalization.  |
| `autoCorrect`    | `string`  | iOS autocorrect.                  |
| `enterKeyHint`   | `string`  | Virtual-keyboard enter-key label. |
| `inputMode`      | `string`  | Virtual-keyboard type.            |
| `spellCheck`     | `boolean` | Spellcheck on the inner input.    |

## Accessibility

- Give the field a visible `label`, or pass `aria-label` / `aria-labelledby` when the label is hidden.
- `description` is the accessible helper. On error, `errorMessage` replaces it.
- The visibility toggle is in the tab order and uses a localized Show/Hide password name. When the field is invalid, the toggle is replaced by a decorative status icon that is not a tab stop.

## RTL and Language

In RTL, the label row, checklist, and feedback follow `dir`. The entered value stays left-to-right with English typography metrics so passwords keep their character order. On `lang="dv"` pages, labels, helpers, and default requirement copy use Dhivehi; the value does not switch to `MV_Faseyha`.
