# TextArea

Use TextArea for longer copy — comments, descriptions, messages. It follows the same label, helper, and validation pattern as [Input](/docs/input/), and adds a character counter plus vertical resize.

## Import

```tsx
import { TextArea } from '@veli-design/react/textarea';
```

## Usage

<div className="preview mb-4 rounded-lg border p-4">
  <TextAreaUsageDemo client:visible />
</div>

```tsx
<TextArea
  label="Message"
  isOptional
  placeholder="Tell us how we can help"
  description="Helper text"
  maxLength={280}
/>
```

Setting `maxLength` shows a live character counter. Pass `showCharacterCounter={false}` to hide it. The field resizes vertically by default; use `isResizable={false}` to lock the height, or `minHeight` / `maxHeight` to bound it.

## Appearances

`default` uses the underline shell. `outline` draws a bordered field. Size the field with `sm`, `md`, or `lg`.

<div className="preview mb-4 rounded-lg border p-4">
  <TextAreaAppearancesDemo client:visible />
</div>

```tsx
<TextArea label="Default" placeholder="Write a note" />
<TextArea appearance="outline" label="Outline" placeholder="Write a note" />
```

## Validation

When `isInvalid` is set, `errorMessage` replaces the helper text.

<div className="preview mb-4 rounded-lg border p-4">
  <TextAreaValidationDemo client:visible />
</div>

```tsx
<TextArea
  label="Details"
  placeholder="Enter details"
  isInvalid
  errorMessage="This field needs attention."
/>
```

## API Reference

TextArea is a Veli field on React Aria [`TextField`](https://react-spectrum.adobe.com/react-aria/TextField.html), which wraps a native `<textarea>`. Props below follow that stack.

### TextArea

Veli-specific props for the composed field.

| Prop                    | Type                       | Default          | Description                                                          |
| :---------------------- | :------------------------- | :--------------- | :------------------------------------------------------------------- |
| `appearance`            | `'default' \| 'outline'`   | `'default'`      | Underline or bordered field.                                         |
| `size`                  | `'sm' \| 'md' \| 'lg'`     | `'md'`           | Field size.                                                          |
| `label`                 | `ReactNode`                | -                | Visible label.                                                       |
| `isOptional`            | `boolean`                  | `false`          | Shows localized Optional beside the label. Hidden when `isRequired`. |
| `infoTooltip`           | `ReactNode`                | -                | Content for the header info tooltip.                                 |
| `infoTooltipAriaLabel`  | `string`                   | Localized string | Accessible name for the info tooltip trigger.                        |
| `labelIcon`             | `ReactNode`                | -                | Small icon after the label.                                          |
| `description`           | `ReactNode`                | -                | Helper text beneath the field.                                       |
| `errorMessage`          | `ReactNode`                | -                | Error text shown when `isInvalid`.                                   |
| `showRequiredIndicator` | `boolean`                  | `true`           | Shows the required asterisk when `isRequired`.                       |
| `showCharacterCounter`  | `boolean`                  | with `maxLength` | Shows the character counter.                                         |
| `isResizable`           | `boolean`                  | `true`           | Allows vertical resize. Off when disabled or read-only.              |
| `minHeight`             | `number`                   | size shell       | Lower resize bound, in pixels.                                       |
| `maxHeight`             | `number`                   | -                | Upper resize bound, in pixels.                                       |
| `className`             | `string`                   | -                | Layout class on the root (width, margin, flex/grid).                 |
| `ref`                   | `Ref<HTMLTextAreaElement>` | -                | Forwarded to the inner textarea.                                     |

### TextField

React Aria’s headless [`TextField`](https://react-spectrum.adobe.com/react-aria/TextField.html#props). These props pass through. The React Aria docs cover the rest, except the exclusions below.

| Prop           | Type                      | Default | Description                    |
| :------------- | :------------------------ | :------ | :----------------------------- |
| `value`        | `string`                  | -       | Controlled value.              |
| `defaultValue` | `string`                  | -       | Uncontrolled initial value.    |
| `onChange`     | `(value: string) => void` | -       | Called when the value changes. |
| `isDisabled`   | `boolean`                 | `false` | Disables the field.            |
| `isInvalid`    | `boolean`                 | `false` | Marks the field invalid.       |
| `isReadOnly`   | `boolean`                 | `false` | Prevents editing.              |
| `isRequired`   | `boolean`                 | `false` | Marks the field required.      |
| `name`         | `string`                  | -       | Native form field name.        |
| `validate`     | `function`                | -       | Custom validation.             |
| `autoFocus`    | `boolean`                 | `false` | Focuses the field on mount.    |

Not forwarded from `TextField`:

| Prop         | Why                                                                 |
| :----------- | :------------------------------------------------------------------ |
| `children`   | Veli owns the field composition.                                    |
| `style`      | Not supported.                                                      |
| `className`  | Replaced by Veli’s layout `className` on the root.                  |
| `spellCheck` | Omitted from `TextField` and applied to the inner textarea instead. |

### Native textarea

The native `<textarea>` that React Aria wraps. These attributes are applied to that element. `maxLength` also turns on the character counter unless `showCharacterCounter` is `false`.

| Prop             | Type      | Description                       |
| :--------------- | :-------- | :-------------------------------- |
| `placeholder`    | `string`  | Placeholder for an empty field.   |
| `maxLength`      | `number`  | Maximum length.                   |
| `minLength`      | `number`  | Minimum length.                   |
| `rows`           | `number`  | Initial visible row count.        |
| `autoComplete`   | `string`  | Browser autocomplete token.       |
| `autoCapitalize` | `string`  | Virtual-keyboard capitalization.  |
| `autoCorrect`    | `string`  | iOS autocorrect.                  |
| `enterKeyHint`   | `string`  | Virtual-keyboard enter-key label. |
| `inputMode`      | `string`  | Virtual-keyboard type.            |
| `spellCheck`     | `boolean` | Spellcheck on the inner textarea. |
| `wrap`           | `string`  | How text wraps.                   |

## Accessibility

- Give the field a visible `label`, or pass `aria-label` / `aria-labelledby` when the label is hidden.
- `description` is the accessible helper. On error, `errorMessage` replaces it.
- Resize is pointer-drag only, same as a native textarea. The handle is not in the tab order, and it is hidden when the field is disabled or read-only.

## RTL and Language

On `lang="dv"` pages, entered text uses `MV_Faseyha`, same as Input. In RTL, the label row and resize handle follow `dir`. The character counter stays left-to-right so the count does not reverse.
