# Avatar

The Avatar component represents a person, agency, or service with an image, initials, or icon.

## Import

```tsx
import { Avatar } from '@tradenetcorp/veli-ui/avatar';
```

## API Reference

| Prop         | Type                                                                                                               | Default  | Description                                                                                 |
| :----------- | :----------------------------------------------------------------------------------------------------------------- | :------- | :------------------------------------------------------------------------------------------ |
| `type`       | `'image' \| 'initials' \| 'icon' \| 'agencyIcon'`                                                                  | `'icon'` | Preferred content when `src` and `initials` do not resolve first.                           |
| `appearance` | `'blue' \| 'neutral' \| 'emerald' \| 'yellow' \| 'orange' \| 'magenta' \| 'indigo' \| 'teal' \| 'green' \| 'lime'` | `'blue'` | Surface and content color.                                                                  |
| `size`       | `'60' \| '52' \| '44' \| '36' \| '28' \| '20' \| '16'`                                                             | `'44'`   | Diameter in pixels; scales icon and initials.                                               |
| `initials`   | `string`                                                                                                           | -        | Name or initials; takes priority over `type` when set. Sizes `16` and `20` show one glyph.  |
| `src`        | `string`                                                                                                           | -        | Image URL; takes priority when loadable. On error, falls back to `initials` when available. |
| `alt`        | `string`                                                                                                           | -        | Accessible name for every content type.                                                     |

All other `div` attributes are supported.

## Accessibility

- Pass a meaningful `alt` for every avatar.
- Without `alt`, initials fall back to the `initials` string; agency icons to `"Agency"`; otherwise `"User"`.
- Avatar is a non-interactive `div`. Wrap it in a button or link when it should be actionable.

## RTL and Language

With `VeliProvider` set to Dhivehi (`language="dv"`), Latin `initials` sources map to Thaana glyphs, including digraphs such as `SH` → `ޝ`.
