# Breadcrumbs

<DocsTab id="overview">

A breadcrumb trail shows where a page sits in a service's structure and lets people go back up a level in one step. Use it on pages three or more levels deep, especially when people arrive from search or a direct link. Each earlier level is a link and the last crumb is the current page.

<DocsResources
  source="https://github.com/veli-design/veli/blob/main/packages/react/src/breadcrumbs.tsx"
  storybook="https://storybook.veli.design/?path=/docs/components-breadcrumbs--docs"
/>

## When to use

### Use breadcrumbs when

- A page belongs to a hierarchy with several levels, such as Services, then Permits, then Fishing permit.
- People need to go back to earlier levels.
- People arrive from search or a deep link and need to know where they are.
- A long trail needs an overflow menu for hidden levels.

### Don't use breadcrumbs when

- The site is one or two levels deep. The page title is enough.
- People are in a linear flow, such as a multi-step form. Give them a clear back action with a Link.
- You need the main navigation of a site or service. Breadcrumbs only add to it.
- People switch between peer sections on the same page. Use Tabs.

<DocsAnatomy>

1. **Trail**

   The list of crumbs. It wraps to a second line when it runs out of room. In code it is Breadcrumbs, and the list has no background or padding.

2. **Link crumb**

   An earlier level people can go back to. It is the only interactive crumb, so hover, pressed, focus and disabled apply here. In code, Breadcrumb with an href.

3. **Separator**

   A slash added after every crumb except the current page. It is decorative, so screen readers skip it. In code it is added by CSS after each list item.

4. **Current page**

   The page people are on. It has no link and no separator after it. In code, the last Breadcrumb.

5. **Back link**

   Optional. A Back link with a caret and a short divider, at the start of the trail. In code, showBackLink on Breadcrumbs, or BreadcrumbBackLink.

6. **Overflow**

   Stands for the levels hidden between the first crumb and the current page. In code, BreadcrumbOverflow, or a Breadcrumb without an href for a plain ellipsis.

</DocsAnatomy>

## Content guidelines

### Use the page title

Use each destination page's title, or words close to it, as the crumb label. Name the same place the same way every time.

| Do                                         | Don't                                              |
| :----------------------------------------- | :------------------------------------------------- |
| Fishing permit                             | Permit page (not the page title)                   |
| Home / Services / Permits / Fishing permit | Back / Level 2 / Level 3 / Current (generic names) |

### Keep labels short

Keep labels to one to three words. Long titles can be shortened, but keep the meaning.

| Do             | Don't                                              |
| :------------- | :------------------------------------------------- |
| Fishing permit | Commercial fishing permit application (four words) |

### Start with Home

The first crumb is usually Home or the service root.

| Do               |
| :--------------- |
| Home             |
| Renew a passport |

### Service names

When a crumb links to a service, use the service name as its page title does, verb first. Content wins over the three-word limit when a shorter name would be unclear.

| Do               | Don't                        |
| :--------------- | :--------------------------- |
| Renew a passport | Passport renewal (noun form) |

### Sentence case, no punctuation

| Do             | Don't                         |
| :------------- | :---------------------------- |
| Fishing permit | Fishing Permit (title case)   |
| Permits        | Permits. (trailing full stop) |

Never type the slash separator into a label. Breadcrumbs draw it.

### Back link

When the trail shows the back link, keep its label Back: it returns to the previous page with answers kept.

### Built-in text and Dhivehi

Breadcrumbs have built-in English text: the back link label Back, the overflow trigger name Show hidden breadcrumb pages and the overflow menu name Hidden breadcrumb pages. They stay English unless you pass Dhivehi, so pass backLinkLabel, label and menuLabel, and the trail's aria-label, on Dhivehi pages.

| Do                       | Don't                                                                      |
| :----------------------- | :------------------------------------------------------------------------- |
| backLinkLabel="ފަހަތަށް" | The default Back in a Dhivehi trail (English label in a Dhivehi interface) |

Use the native Dhivehi page titles, and check that the trail still fits on small screens.

## Crumbs

A trail is built from three kinds of crumb.

<DocsFigure
  src="/images/docs/breadcrumbs/breadcrumbs-crumbs-1.webp"
  darkSrc="/images/docs/breadcrumbs/breadcrumbs-crumbs-1-dark.webp"
  alt="Three examples labelled Type link, current and overflow: Services followed by a slash in muted text, Fishing permit in darker text with no slash, and an ellipsis followed by a slash."
  width="2400"
  height="560"
  caption="The three kinds of crumb: link, current and overflow."
/>

- **Link**: an earlier level, with an href. The only interactive crumb.
- **Current**: the last crumb, the page people are on. It is never interactive.
- **Overflow**: the ellipsis crumb, which stands for collapsed levels. With BreadcrumbOverflow it is a trigger that opens a menu of the hidden levels. A Breadcrumb without an href shows a plain ellipsis instead.

## Back link

Illustration needed: the trail "Back | Services / Fishing permit", with Back in link colour with a left caret, followed by a short vertical divider.

_A trail with the back link._

Use the back link when people need a direct return action before the trail. It sits before the first crumb, separated by a divider, in the link colour with a caret that points back. Turn it on with showBackLink and backLinkHref, or place BreadcrumbBackLink yourself before the other crumbs.

| :------- | :--------------------- | :-------------------------------------------------------------------- |
| Default  | No interaction         | Text `text/base/muted`                                                |

| Focus    | Keyboard focus         | Focus ring, text `text/base/DEFAULT`                                  |
| Disabled | isDisabled             | Text `text/base/inactive`. Not clickable and skipped by Tab           |

States apply to link crumbs only. The current page is never interactive. The overflow crumb has default, hover, pressed and open states in Figma; open shows the menu.

## Behaviour

- **Navigation**: each link crumb follows its href. A crumb can change app state with onPress instead.
- **Data-driven trails**: pass items, with an id for each, and handle onAction(key) when application state controls the path. Activating an earlier crumb collapses the trail to that level.
- **Disabled crumbs**: use isDisabled when a level that was shown is no longer available. The label stays in the trail but can't be used.
- **Wrapping**: the trail wraps across lines on narrow screens and never scrolls sideways. When space is short, collapse middle levels into the overflow crumb.
- **Back link with a render function**: Breadcrumbs don't add the automatic back link when their children use a render function. Place BreadcrumbBackLink yourself.

- The back link caret follows the direction, so it points right in Dhivehi.

- The overflow menu's language and direction follow VeliProvider.
- In code, wrap the page in VeliProvider with language set to dv. In Figma, design Dhivehi screens with breadcrumbsDv and breadcrumbItemDv.

## Overflow

Collapse long trails deliberately: keep the first crumb and current page visible, and put middle levels in `BreadcrumbOverflow`.

<div className="preview preview--collapsible mb-4 rounded-lg border p-4">
  <BreadcrumbsOverflowDemo client:visible />
</div>

```tsx
const hiddenPages = [
  { id: 'applications', label: 'Applications', href: '/applications' },
  { id: 'permits', label: 'Permits', href: '/permits' },
];

<Breadcrumbs aria-label="Application breadcrumb">
  <Breadcrumb href="/">Home</Breadcrumb>
  <BreadcrumbOverflow items={hiddenPages} />
  <Breadcrumb href="/permits/fishing">Fishing permits</Breadcrumb>
  <Breadcrumb>New application</Breadcrumb>
</Breadcrumbs>;
```

`BreadcrumbOverflow` is caller-managed; it opens a menu for hidden levels. Breadcrumbs wraps on narrow screens and never scrolls horizontally.

## Disabled crumbs

Use `isDisabled` when a previously visible level is unavailable. It keeps the label in the trail but removes navigation and the item from the tab order.

<div className="preview preview--collapsible mb-4 rounded-lg border p-4">
  <BreadcrumbsDisabledDemo client:visible />
</div>

```tsx
<Breadcrumbs aria-label="Breadcrumb">
  <Breadcrumb href="/">Home</Breadcrumb>
  <Breadcrumb href="/services/archived" isDisabled>
    Archived services
  </Breadcrumb>
  <Breadcrumb>Permit details</Breadcrumb>
</Breadcrumbs>
```

## Data-driven trails

Pass `items`, `id`, and `onAction` when application state controls the visible path.

<div className="preview preview--collapsible mb-4 rounded-lg border p-4">
  <BreadcrumbsDataDrivenDemo client:visible />
</div>

```tsx
<Breadcrumbs items={items} aria-label="Application breadcrumb" onAction={setCurrentLevel}>
  {(item) => <Breadcrumb href={item.href}>{item.label}</Breadcrumb>}
</Breadcrumbs>
```

## Accessibility, RTL, and motion

Give every trail an `aria-label` unless an adjacent heading already names it. The final `Breadcrumb` is automatically marked as the current page and is not interactive; separators are decorative. Linked crumbs are keyboard reachable, disabled crumbs are skipped, and the interactive crumbs retain a visible focus ring.

Use `VeliProvider language="dv"` for Dhivehi. The list, separators, and back-link caret mirror automatically for RTL, while the slash separator stays `/`. Links and the current page use body-sm medium in both English and Dhivehi. The default “…” overflow crumb uses body-sm regular.

Hover, pressed, and focus changes animate colors only with Veli's normal-duration easing. These transitions are disabled when the user prefers reduced motion.

## API Reference

### `Breadcrumbs`

| Prop              | Type              | Description                                                                                  |
| :---------------- | :---------------- | :------------------------------------------------------------------------------------------- |
| `items`           | `Iterable<T>`     | Supplies a collection for data-driven breadcrumb rendering.                                  |
| `onAction`        | `(key) => void`   | Called when a non-current breadcrumb is activated.                                           |
| `showBackLink`    | `boolean`         | Adds the separated back-link treatment for static child breadcrumbs.                         |
| `backLinkHref`    | `string`          | Navigates the generated back link.                                                           |
| `backLinkLabel`   | `ReactNode`       | Labels the generated back link. Defaults to `Back`.                                          |
| `backLinkOnPress` | `(event) => void` | Handles generated back-link activation without an `href`.                                    |
| `aria-label`      | `string`          | Gives the breadcrumb trail an accessible name when there is no surrounding heading or label. |
| `className`       | `string`          | Adds local layout overrides to the root breadcrumb list.                                     |

### `Breadcrumb`

| Prop            | Type              | Description                                                                                              |
| :-------------- | :---------------- | :------------------------------------------------------------------------------------------------------- |
| `href`          | `string`          | Navigates to the linked hierarchy level when activated.                                                  |
| `isDisabled`    | `boolean`         | Shows the crumb as unavailable, removes interaction, and skips it in the tab order.                      |
| `onPress`       | `(event) => void` | Handles breadcrumb activation when the trail is used for app-state changes instead of normal navigation. |
| `id`            | `Key`             | Useful in collection-driven breadcrumb trails so `onAction` can identify the selected crumb.             |
| `className`     | `string`          | Adds local overrides to the list item wrapper.                                                           |
| `linkClassName` | `string`          | Adds local overrides to the interactive link or plain-text element.                                      |

### `BreadcrumbBackLink`

`BreadcrumbBackLink` is the composable equivalent of `showBackLink`. Use `label`, `href`, `onPress`, `isDisabled`, `target`, and `rel` to configure it, or supply custom children while retaining its separator and RTL-aware caret treatment.

### `BreadcrumbOverflow`

Pass `items` with an `id`, `label`, optional `href`, `target`, `rel`, and `isDisabled` for each hidden level. `label` names the overflow trigger and `menuLabel` names its menu for assistive technology; `onAction` receives the selected item key.

All remaining supported React Aria `Breadcrumbs` and `Breadcrumb` props can still be passed through these wrappers.

## Migration from `tone`

`Breadcrumb` no longer accepts the `tone` prop. It did not change rendered styles. Remove it from existing breadcrumbs; use `BreadcrumbBackLink` or `showBackLink` for the dedicated blue back-link treatment.

## Keyboard

| Key                        | Action                                                                  |
| :------------------------- | :---------------------------------------------------------------------- |
| Tab                        | Moves focus to the next link crumb, the back link or the overflow crumb |
| Shift + Tab                | Moves focus to the previous one                                         |
| Enter                      | Follows the focused link crumb or back link                             |
| Enter, Space or Down arrow | Opens the overflow menu from the focused overflow crumb                 |
| Up and Down arrows         | Move through the hidden levels in the open overflow menu                |
| Escape                     | Closes the overflow menu                                                |

The current page and disabled crumbs are skipped.

## Screen readers

- The trail is an ordered list. Name it with aria-label, such as Breadcrumb. Don't repeat the role in the name: not Breadcrumb navigation. Pass the Dhivehi name on Dhivehi pages.
- When the trail is page navigation, place it in a nav landmark. Leave the landmark out for breadcrumbs inside tables or popovers, where it only adds noise.
- The current page is marked with aria-current="page".
- The slash separator is decorative and hidden from assistive technology. Never put it in the label text.
- The overflow crumb is a button that opens a menu. It is named Show hidden breadcrumb pages and its menu Hidden breadcrumb pages; change them with label and menuLabel.
- A disabled crumb is announced as disabled.

## Focus

Keyboard focus shows a 2px focus ring in `border/focus` with a transparent 2px gap around the crumb, following its 6 radius. The ring sits outside the crumb, so focusing doesn't move the trail. Only link crumbs and the back link can receive focus; the current page and a plain ellipsis crumb can't. Never remove the ring.

## Target size

Each crumb is at least 24px tall. Keep the 8px side padding so the target stays comfortable.

## Contrast

Use the breadcrumb tokens as they are. Don't override them with custom colours.

## Reduced motion

When people prefer reduced motion, the colour transitions are turned off. Nothing extra is needed from you.

## Right to left

Set the language with VeliProvider (language dv). The list, separators and back link caret mirror on their own. Pass Dhivehi crumb labels, backLinkLabel, the overflow label and menuLabel, and the trail's aria-label yourself.
