# Breadcrumbs

`Breadcrumbs` communicates hierarchy and lets people move back up through nested pages or workflows. This Veli wrapper follows the React Aria breadcrumb example model, with a styled `Breadcrumbs` list and ergonomic `Breadcrumb` items. By default, the first breadcrumb link receives the Veli blue emphasis, intermediate links use a quieter inactive text treatment, the current page uses a subtle neutral tone, and placeholder crumbs like `...` can be rendered as plain text by omitting `href`.

## Import

```tsx
import { Breadcrumb, Breadcrumbs } from '@tradenetcorp/veli-ui/breadcrumbs';
```

```tsx
<Breadcrumbs aria-label="Breadcrumb">
  <Breadcrumb href="#">Home</Breadcrumb>
  <Breadcrumb href="#">Services</Breadcrumb>
  <Breadcrumb href="#">Permits</Breadcrumb>
  <Breadcrumb>Fishing permit</Breadcrumb>
</Breadcrumbs>
```

## API Reference

### `Breadcrumbs`

| Prop         | Type            | Description                                                                                  |
| :----------- | :-------------- | :------------------------------------------------------------------------------------------- |
| `items`      | `Iterable<T>`   | Supplies a collection for data-driven breadcrumb rendering.                                  |
| `onAction`   | `(key) => void` | Called when a non-current breadcrumb is activated.                                           |
| `aria-label` | `string`        | Gives the breadcrumb trail an accessible name when there is no surrounding heading or label. |
| `className`  | `string`        | Adds local layout overrides to the root breadcrumb list.                                     |

### `Breadcrumb`

| Prop            | Type                  | Description                                                                                              |
| :-------------- | :-------------------- | :------------------------------------------------------------------------------------------------------- |
| `href`          | `string`              | Navigates to the linked hierarchy level when activated.                                                  |
| `tone`          | `'accent' \| 'muted'` | Chooses between the Veli blue accent treatment and the muted neutral breadcrumb style.                   |
| `isDisabled`    | `boolean`             | Shows the crumb as unavailable and removes interaction.                                                  |
| `onPress`       | `(event) => void`     | Handles breadcrumb activation when the trail is used for app-state changes instead of normal navigation. |
| `id`            | `Key`                 | Useful in collection-driven breadcrumb trails so `onAction` can identify the selected crumb.             |
| `className`     | `string`              | Adds local overrides to the list item wrapper.                                                           |
| `linkClassName` | `string`              | Adds local overrides to the interactive link element.                                                    |

All remaining supported React Aria `Breadcrumbs` and `Breadcrumb` props can still be passed through these wrappers.
