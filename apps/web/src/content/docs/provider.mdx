# CoralProvider

`CoralProvider` is the integration point for Coral's supported language and direction modes. Consumers choose a supported language, and Coral maps that to locale, DOM language, and DOM direction.

## Import

```tsx
import { CoralProvider } from '@tradenetcorp/coral-ui/provider';
```

## Usage

```tsx
<CoralProvider language="en">
  <App />
</CoralProvider>
```

```tsx
<CoralProvider language="dv">
  <App />
</CoralProvider>
```

## Supported Modes

| `language` | Content language | Locale  | Direction |
| :--------- | :--------------- | :------ | :-------- |
| `en`       | English          | `en-US` | `ltr`     |
| `dv`       | Dhivehi          | `dv-MV` | `rtl`     |

Consumers should not pass `locale` and `dir` separately. Coral owns that mapping so unsupported combinations cannot be created by accident.

## Helpers

```tsx
import { getCoralLanguageConfig, useCoralLanguage } from '@tradenetcorp/coral-ui/provider';
```

`useCoralLanguage` returns the active Coral language config inside a provider subtree. `getCoralLanguageConfig` returns the same mapping without reading React context.

## Direction Contract

The provider applies `lang` and `dir` to its wrapper element. Coral components that need language or direction awareness should read those attributes from the provider contract instead of deriving direction from a browser locale fallback.

React Aria still receives the mapped locale for i18n behavior. Direction-sensitive Coral component behavior is handled separately by the component implementation.

## Typography

English and Dhivehi typography styles are distinct in design. `CoralProvider` defines the language contract, but it does not generate or override typography tokens. Dhivehi typography should use the exact exported design token values when those token styles are available.

## Props

| Prop       | Type           | Default | Description                                                                 |
| :--------- | :------------- | :------ | :-------------------------------------------------------------------------- |
| `language` | `'en' \| 'dv'` | `'en'`  | Selects Coral's supported language and direction mode.                      |
| `children` | `ReactNode`    | -       | Application or component subtree that should inherit the language contract. |
