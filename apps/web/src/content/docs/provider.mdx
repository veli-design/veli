# VeliProvider

`VeliProvider` is the integration point for Veli's supported language, direction, and color scheme modes. Consumers choose a supported language, and Veli maps that to locale, DOM language, DOM direction, and theme attributes.

## Import

```tsx
import { VeliProvider } from '@veli-design/react/provider';
```

## Usage

```tsx
<VeliProvider language="en">
  <App />
</VeliProvider>
```

```tsx
<VeliProvider language="dv">
  <App />
</VeliProvider>
```

```tsx
<VeliProvider colorScheme="system">
  <App />
</VeliProvider>
```

## Supported Language Modes

| `language` | Content language | Locale  | Direction |
| :--------- | :--------------- | :------ | :-------- |
| `en`       | English          | `en-GB` | `ltr`     |
| `dv`       | Dhivehi          | `dv-MV` | `rtl`     |

Consumers should not pass `locale` and `dir` separately. Veli owns that mapping so unsupported combinations cannot be created by accident.

## Supported Color Schemes

| `colorScheme` | Behavior                                                        |
| :------------ | :-------------------------------------------------------------- |
| `system`      | Resolves to the user's `prefers-color-scheme` media preference. |
| `light`       | Forces light mode for the provider subtree.                     |
| `dark`        | Forces dark mode for the provider subtree.                      |

The provider applies `data-theme`, `data-color-scheme`, the `.dark` class when resolved dark, and the CSS `color-scheme` utility to its wrapper element. App shells that render portaled UI should also keep `document.documentElement` in sync with the same `.dark` class so overlays inherit the active token mode.

## Client-side routing

Pass `navigate` and `useHref` from the guide for your router. [Frameworks](/getting-started/frameworks/) shows the wiring for Next.js, React Router, and TanStack Start. `navigate` is optional. Without it, `href` uses a full page load.

## Helpers

```tsx
import {
  getVeliLanguageConfig,
  useVeliColorScheme,
  useVeliLanguage,
} from '@veli-design/react/provider';
```

`useVeliLanguage` returns the active Veli language config inside a provider subtree. `getVeliLanguageConfig` returns the same mapping without reading React context.

`useVeliColorScheme` returns both the requested `colorScheme` and the resolved `light` or `dark` mode for the current provider subtree.

## Direction Contract

The provider applies `lang` and `dir` to its wrapper element. Veli components that need language or direction awareness should read those attributes from the provider contract instead of deriving direction from a browser locale fallback.

React Aria still receives the mapped locale for i18n behavior. Direction-sensitive Veli component behavior is handled separately by the component implementation.

## Typography

English and Dhivehi typography styles are distinct in design. `VeliProvider` applies the inherited `lang` value that Veli's generated `type-*` utilities use to switch to exported Dhivehi typography values.

Consumers should keep using the same semantic `type-*` classes in both languages. Font family, size, line height, weight, and letter spacing switch automatically when `language="dv"` is active.

## API Reference

| Prop                        | Type                            | Default    | Description                                                                 |
| :-------------------------- | :------------------------------ | :--------- | :-------------------------------------------------------------------------- |
| `language`                  | `'en' \| 'dv'`                  | `'en'`     | Selects Veli's supported language and direction mode.                       |
| `colorScheme`               | `'system' \| 'light' \| 'dark'` | `'system'` | Selects Veli's requested color scheme mode.                                 |
| `navigate`                  | `(path, options?) => void`      | -          | Client-side navigate function; enables React Aria `RouterProvider`.         |
| `useHref`                   | `(path) => string`              | -          | Optional href resolver for the configured client-side router.               |
| `disableTransitionOnChange` | `boolean`                       | `false`    | Suppresses CSS transitions for one frame while the theme changes.           |
| `className`                 | `string`                        | -          | Adds classes to the provider wrapper.                                       |
| `children`                  | `ReactNode`                     | -          | Application or component subtree that should inherit the provider contract. |
