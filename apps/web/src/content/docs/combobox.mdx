# ComboBox

<DocsTab id="overview">

A combobox lets people choose one option from a long list by typing to narrow it down, such as an island or a service centre. Use it in forms when the list is too long to scroll and people know the name of what they want. It can group options under titles and, when you allow it, accept a value that is not in the list.

  source="https://github.com/veli-design/veli/blob/main/packages/react/src/combobox.tsx"

## When to use

### Use a combobox when

- The list is long enough that typing to filter is faster than scrolling, such as islands or services.
- People know the option they want and can type part of its name.
- People choose one option from a known list, which may be grouped.
- A value outside the list is allowed (allowsCustomValue).

### Don't use a combobox when

- The list is short and people should see every option at once. Use Radio button or Select.
- People can choose more than one option. Use Checkbox.
- People type free text with no list. Use Input.
- The typed text searches content or results rather than choosing a value. Use Search.

<DocsAnatomy>

1. **Label**

   names the field. In code: label.

2. **Info icon**

   an optional 16px info icon that opens a tooltip. Its accessible name is More information by default. In code: infoTooltip and infoTooltipAriaLabel.

3. **Optional**

   shows Optional after the label when the field is marked isOptional. It is hidden when the field is required, and the word cannot be changed.

4. **Required indicator**

   the asterisk shown when the field is required. Set showRequiredIndicator to false to hide it. In code: isRequired.

5. **Field**

   the input shell. It holds the typed text or the placeholder, the line or border, the background and the focus ring.

6. **Menu trigger**

   a 20px caret button that opens the list. It flips while the list is open. Replace the icon with menuTriggerIcon.

7. **Description**

   helper text below the field. While the field is invalid, errorMessage takes its place.

8. **Popover**

   the list surface, 4 below the field and as wide as it. It scrolls past 240.

9. **Section header**

   groups options under a title. In code: ComboBoxSection title.

10. **Option**

one choice, with text and an optional description, icon and end content. In code: ComboBoxItem. 11. **Selected check**

marks the selected option.

</DocsAnatomy>

## Content guidelines

### Label

Name what is being chosen, in sentence case, with no colon.

| Do             | Don't                                                        |
| :------------- | :----------------------------------------------------------- |
| Island         | Choose your island: (names the action and ends with a colon) |
| Service centre |                                                              |

### Placeholder

Use the placeholder only to hint at what to type. Never put information people need only in the placeholder: it disappears as they type. Don't end it with punctuation or an ellipsis.

| Do              | Don't                                                                                                     |
| :-------------- | :-------------------------------------------------------------------------------------------------------- |
| Search location | Choose the island where you live, as written on your ID card (information that disappears as people type) |
| Search islands  |                                                                                                           |

### Helper text

Say what the list holds or that typing narrows it, in one short sentence with no full stop.

| Do                                              | Don't                                                                     |
| :---------------------------------------------- | :------------------------------------------------------------------------ |
| Start typing to narrow the list                 | Start typing to narrow the list. (a one-sentence hint takes no full stop) |
| The centre where you will collect your passport | Error (does not say what is wrong or how to fix it)                       |

With allowsCustomValue, say that people can type a value that is not in the list.

| Do                                                 | Don't                                                                      |
| :------------------------------------------------- | :------------------------------------------------------------------------- |
| Choose your island, or type it if it is not listed | Start typing to narrow the list (suggests only listed values are accepted) |

### Error message

Say what is wrong and how to fix it. Start with Choose when an answer is missing, don't say please, and leave the full stop off one sentence.

| Do                                                             | Don't                                                                       |
| :------------------------------------------------------------- | :-------------------------------------------------------------------------- |
| Choose a location from the list                                | Please choose a supported location. (says please and ends with a full stop) |
| Choose the service centre where you will collect your passport | Invalid selection (does not say what to do)                                 |

### Options

Use the names people know, in sentence case, and keep options short and distinct so filtering finds them. Write Malé with an acute é, also in Hulhumalé. Write island and atoll in lower case except inside a name, and use the full form in forms: Naifaru, Lhaviyani Atoll.

| Do        | Don't                                  |
| :-------- | :------------------------------------- |
| Malé      | K. Male' (never K. Malé)               |
| Hulhumalé | MLE (a code, not the name people know) |
| Addu City |                                        |

### No matches

Replace the default No matches found. with emptyState. Repeat the typed text exactly, in single curly quotes, and give one next step. Wrap the echoed text in bdi so it keeps its own direction.

| Do                                                                   | Don't                                                      |
| :------------------------------------------------------------------- | :--------------------------------------------------------- |
| No islands match ‘Nayfaru’. Check the spelling or type another name. | No data (says nothing about the search or what to do next) |

### Optional and required

Mark whichever is rarer in the form: Optional on optional fields when most are required, or the asterisk on required fields when most are optional. Optional is hidden when the field is required.

### Long text

Truncate only non-essential text, and only when the full text is shown elsewhere. Truncation sits at the inline end, which is the left in Dhivehi.

### Built-in strings and Dhivehi

Combobox has three built-in strings in English and Dhivehi: Optional, which you cannot reword; the info button name More information (އިތުރު މަޢުލޫމާތު), which you set with infoTooltipAriaLabel so it names the topic, such as More information about service centres; and the empty message No matches found. (ނަތީޖާއެއް ނުފެނުނު.), which you replace with emptyState. The button name Show suggestions, the list name Suggestions, the option count and selection announcements and the hidden Dismiss buttons have no prop and stay in English on Dhivehi pages.

Write Dhivehi labels natively rather than transliterating, and keep them as short as the English.

## Behaviour

- **Filtering**: typing filters the list to options that contain the text, using the language's rules.
- **Opening**: the list opens when people type, with the Down or Up arrow, or from the caret button. Escape closes it.
- **Selection**: choosing an option fills the field with its text and closes the list. Choosing only sets the value: nothing navigates or submits, and people continue with a separate button, such as Continue.
- **Leaving the field**: leaving with unmatched text restores the last selection, unless custom values are allowed.
- **Custom value**: with allowsCustomValue the typed text is kept even when it matches no option, and the form stores that text.
- **Empty state**: when nothing matches, the list shows No matches found. Pass emptyState with a message that repeats what was typed and says what to do next.
- **Controlled**: control the typed text with inputValue and the choice with value or selectedKey, or leave both uncontrolled. Use one selection API.
- **Width**: the field fills its container. Set the width on the root with className, which only sets outer layout. Combobox takes no direct children on the root and no style overrides.
- **Language**: filtering follows the VeliProvider language. An explicit lang sets the filtering locale, and an explicit dir also sets the direction of the list and the tooltip.

- In Dhivehi everything mirrors: the label row starts on the right, the caret sits on the left, and the selected check moves to the left of each option.

- People may type Latin text in a Dhivehi combobox, and filtering accepts both scripts. Set dir auto on the input, and wrap typed text echoed back in emptyState in bdi.
- In code, wrap the app in VeliProvider with language set to dv, or set lang on a single field. In Figma, design Dhivehi screens with ComboboxDv.

```tsx
    { id: 'mv', name: 'Maldives' },
    { id: 'lk', name: 'Sri Lanka' },
  ]}
>
  {(item) => <ComboBoxItem>{item.name}</ComboBoxItem>}
</ComboBox>
```

## API Reference

ComboBox is a Veli field on React Aria [`ComboBox`](https://react-spectrum.adobe.com/react-aria/ComboBox.html), composed with `Input`, `Button`, `Popover`, and `ListBox`. Props below follow that stack. `Key` is `string | number`; `K` is the selected-key type inferred by the Veli selection props.

### React Aria ComboBox

The following React Aria [`ComboBox`](https://react-spectrum.adobe.com/react-aria/ComboBox.html#props) state, collection, input, and validation props are passed to the headless root. React Aria routes input behavior to the inner input and manages the listbox.

| Prop                            | Type                                                                  | Default                 | Description                                                              |
| :------------------------------ | :-------------------------------------------------------------------- | :---------------------- | :----------------------------------------------------------------------- |
| `items`                         | `Iterable<T>`                                                         | -                       | Controlled collection; filter it yourself when controlling the items.    |
| `defaultItems`                  | `Iterable<T>`                                                         | -                       | Initial collection used with the default filter.                         |
| `selectedKey`                   | `Key \| null`                                                         | -                       | React Aria's controlled selected-key API.                                |
| `defaultSelectedKey`            | `Key \| null`                                                         | -                       | React Aria's uncontrolled initial key.                                   |

| `defaultInputValue`             | `string`                                                              | -                       | Uncontrolled initial search text.                                        |
| `onInputChange`                 | `(value: string) => void`                                             | -                       | Called when search text changes.                                         |
| `menuTrigger`                   | `'focus' \| 'input' \| 'manual'`                                      | `'focus'`               | When suggestions open. Veli supplies this default.                       |
| `onOpenChange`                  | `(isOpen: boolean, trigger?: 'focus' \| 'input' \| 'manual') => void` | -                       | Called when suggestions open or close.                                   |
| `allowsCustomValue`             | `boolean`                                                             | `false`                 | Allows input text outside the collection.                                |
| `allowsEmptyCollection`         | `boolean`                                                             | `false`                 | Allows the listbox to open with no matching options.                     |
| `defaultFilter`                 | `(textValue: string, inputValue: string) => boolean`                  | Locale-aware contains   | Filter used for an uncontrolled collection.                              |
| `disabledKeys`                  | `Iterable<Key>`                                                       | -                       | Keys of options to disable.                                              |
| `isDisabled`                    | `boolean`                                                             | `false`                 | Disables the field.                                                      |
| `isReadOnly`                    | `boolean`                                                             | `false`                 | Prevents editing and opening while keeping the value focusable.          |
| `isInvalid`                     | `boolean`                                                             | `false`                 | Marks the field invalid.                                                 |

| `name`                          | `string`                                                              | -                       | Native form field name.                                                  |
| `form`                          | `string`                                                              | -                       | ID of the form associated with the input.                                |

| `aria-label`, `aria-labelledby` | `string`                                                              | -                       | Accessible name when a visible label is not used.                        |
| `lang`, `dir`                   | `string`                                                              | Active locale/direction | Field language and direction; also applied to popup and tooltip content. |

Supported focus and keyboard handlers and global DOM attributes follow the installed React Aria `ComboBoxProps` type. `ref` and `inputRef` target the native input, but the root does not accept the full `InputHTMLAttributes` API: `autoComplete`, `maxLength`, `inputMode`, and `spellCheck` are not public ComboBox props. Veli does not expose separate `Input`, `Popover`, or `ListBox` prop objects.

Not forwarded unchanged from React Aria `ComboBox`:

| Prop                                                  | Why                                                                                                     |
| :---------------------------------------------------- | :------------------------------------------------------------------------------------------------------ |
| `children`                                            | Replaced by Veli option composition and the collection renderer above; no root render-prop composition. |
| `label`, `description`, `errorMessage`, `placeholder` | Rendered by Veli in the label, helper/error, and inner input slots.                                     |
| `value`, `defaultValue`, `onChange`                   | Replaced by Veli's typed selected-key props above.                                                      |
| `className`                                           | Replaced by Veli's string class on the root; no state-based class function.                             |
| `style`                                               | Not supported on the Veli root.                                                                         |

| Prop        | Type        | Default | Description                    |
| :---------- | :---------- | :------ | :----------------------------- |

## Accessibility

- Give the field a visible `label`, or pass `aria-label` / `aria-labelledby` when the label is hidden.
- Type to filter suggestions. The arrow keys navigate options, Enter selects, and Escape dismisses the listbox.
- `description` is the accessible helper. On error, `errorMessage` replaces it.
- Give render-function, icon-only, or complex options a `textValue` or `aria-label` when their children cannot provide useful text.
- Field, caret, and option feedback respect reduced motion. The info tooltip reuses the shared Tooltip behavior.

<DocsTab id="accessibility">

How the combobox works with keyboards, screen readers and assistive settings. The input has the combobox role and controls a listbox, built on React Aria ComboBox.

## Keyboard

Focus stays in the input while the arrow keys move through options. The caret button is not in the tab order.

| Key                        | Action                                                                                             |
| :------------------------- | :------------------------------------------------------------------------------------------------- |
| Tab                        | Moves focus to the input. In the open list, commits the focused option and moves to the next field |
| Typing                     | Filters the list and opens it                                                                      |
| Down arrow and Up arrow    | Open the list and move through options                                                             |
| Enter                      | Chooses the focused option and closes the list                                                     |
| Escape                     | Closes the list and reverts to the last chosen option                                              |
| Left arrow and Right arrow | Move the text caret in the input                                                                   |

## Screen readers

- The input has the combobox role, autocomplete list, and reports whether the list is open. The active option is announced as people move, through aria-activedescendant.
- The list is a listbox named Suggestions, and each section is a group. The selected option reports that it is selected.
- A live region announces the option count, the group entered and the selected option. This helps screen readers that handle aria-activedescendant poorly, such as VoiceOver on iOS. These announcements stay in English on Dhivehi pages.
- The description and errorMessage are linked to the input and the field is marked invalid, so the message is read with the field. Required and disabled states are exposed too.
- Optional and the required asterisk sit outside the label, so neither is part of the accessible name. isRequired still tells screen readers the field is required.
- Options with icons or custom content need textValue or aria-label, so filtering, the selected value and screen readers get plain text.
- The info button has its own accessible name, More information by default. Set infoTooltipAriaLabel so it names the topic.

## Labels

Every combobox needs a visible label. Never replace it with aria-label or the placeholder.

- Keyboard focus shows a 2px ring in `border/focus` with a 2px offset around the field. It follows the 10 radius and sits outside the field, so focusing does not change its size or move neighbours.
- The ring shows for keyboard focus only. A pointer click shows the active state without the ring.
- In the open list, the active option shows the `menu/hover` background. In forced colours mode it gets an outline.
- Disabled fields cannot be focused. Read-only fields can be focused but not changed.

## List roles

Options look like menu items but keep the listbox and option roles. Never rebuild the list from Menu, and never put buttons, links or checkboxes inside an option.

## Target size

The minimum target size is 24 x 24, and 44 is recommended for touch. The md field is 44 high and the lg field 52, so both reach the touch size. The sm field, 36 high, passes the minimum; keep it to dense layouts. Options are at least 36 high. The info button is 16 x 16, below the 24 x 24 minimum; see Missing or unverified.

## Contrast

Placeholder text in Figma uses `text/base/inactive`, about 2.1 to 2.7:1, which is under 4.5:1. Keep everything people need in the label or helper text. Helper text in `text/base/muted` measures 4.96:1 in light and 5.23:1 in dark in Storybook, which meets 4.5:1.

## Zoom and phones

- Keep the list inside the viewport at high zoom.
- Text inside the field must be at least 16 on phones, so iOS Safari does not zoom. Combobox text is 14 at sm and md and 16 at lg, so use lg on phones.

## Right to left

Set the language with VeliProvider (language dv). The field, placeholder, list, options and sections follow the language and direction. Pass Dhivehi labels, placeholders, options and emptyState yourself. Show suggestions, Suggestions and the live announcements stay in English.
