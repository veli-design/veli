# Link

The Link component provides an accessible, keyboard-navigable link with multiple variants that inherit typography from the surrounding context.

## Import

```tsx
import { Link } from '@tradenetcorp/veli-ui/link';
import { Plus } from 'phosphor-react';
```

import {
  LinkIconsDemo,
  LinkSizesDemo,

## Props

| Prop         | Type                            | Default     | Description                      |
| :----------- | :------------------------------ | :---------- | :------------------------------- |
| `intent`     | `'default' \| 'secondary'`      | `'default'` | The visual category of the link. |
| `underline`  | `'none' \| 'hover' \| 'always'` | `'none'`    | Underline behavior.              |
| `isDisabled` | `boolean`                       | `false`     | Standard disabled state.         |

_Note: All other `react-aria-components` Link props are supported, excluding `className` and `style` overrides._
