# Link

The Link component provides an accessible, keyboard-navigable link with multiple variants and sizes.

## Import

```tsx
import { Link } from '@tradenetcorp/coral-ui/link';
import { ArrowRight, Link as LinkIcon } from 'phosphor-react';
```

import { Link } from '@tradenetcorp/coral-ui/link';
import { ArrowRight, Link as LinkIcon, Plus, DownloadSimple } from 'phosphor-react';

## Usage

<div className="preview p-4 border rounded-lg bg-surface-100 mb-4">
  <Link href="#" client:visible>Link Label</Link>
</div>

```tsx
<Link href="#">Link Label</Link>
```

## Icons

To maintain design consistency, icons should follow these size guidelines:
- **XL Links**: 24px
- **LG Links**: 20px
- **MD/SM Links**: 16px
- **XS Links**: 12px

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `'primary' \| 'secondary' \| 'inverted'` | `'primary'` | The visual category of the link. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | The scale of the link text and icons. |
| `underline` | `'none' \| 'hover' \| 'always'` | `'hover'` | Underline behavior. |
| `isDisabled` | `boolean` | `false` | Standard disabled state. |

*Note: All other `react-aria-components` Link props are supported, excluding `className` and `style` overrides.*
