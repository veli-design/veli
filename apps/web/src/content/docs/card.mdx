# Card

Use Card to group related content on a raised surface: summaries, application status, or short forms. Compose with `Card.Header`, `Card.Title`, `Card.Description`, `Card.Content`, and `Card.Footer`. Prefer [Alert](/docs/alert/) for page-level status banners and [Modal](/docs/modal/) for focused dialogs.

## Import

```tsx
import { Card } from '@veli-design/react/card';
```

## Usage

<div className="preview mb-4 rounded-lg border p-4">
  <CardUsageDemo client:visible />
</div>

```tsx
<Card>
  <Card.Header>
    <Card.Title>Permit application</Card.Title>
    <Card.Description>Track progress and required documents.</Card.Description>
  </Card.Header>
  <Card.Content>
    Your application is under review. We will notify you when a decision is ready.
  </Card.Content>
  <Card.Footer>
    <Button intent="secondary" appearance="transparent" size="sm">
      View details
    </Button>
    <Button size="sm">Continue</Button>
  </Card.Footer>
</Card>
```

Header, description, content, and footer are optional. Pass `action` on `Card.Header` for a trailing control.

## Elevations

Elevation sets the shadow. `interactive` adds hover and press feedback.

</div>

```tsx

<Card elevation="sm">…</Card>
<Card elevation="md">…</Card>
<Card elevation="lg">…</Card>
<Card interactive>…</Card>
```

## With form fields

Use Card to group related inputs for a short form.

<div className="preview mb-4 rounded-lg border p-4">
  <CardFormDemo client:visible />
</div>

```tsx
<Card>
  <Card.Header>
    <Card.Title>Contact details</Card.Title>
    <Card.Description>How we reach you about this application.</Card.Description>
  </Card.Header>
  <Card.Content>
    <Input label="Email" placeholder="name@example.com" />
    <Input label="Phone" placeholder="+960 7XX XXXX" />
    <TextArea label="Notes" placeholder="Anything the reviewer should know" rows={3} />
  </Card.Content>
  <Card.Footer>
    <Button size="sm">Save</Button>
  </Card.Footer>
</Card>
```

## API Reference

### Card

| Prop          | Type                                     | Default | Description                         |
| :------------ | :--------------------------------------- | :------ | :---------------------------------- |
| `elevation`   | `'none' \| 'xs' \| 'sm' \| 'md' \| 'lg'` | `'xs'`  | Shadow depth.                       |
| `spacing`     | `'sm' \| 'md' \| 'lg' \| 'xl'`           | `'md'`  | Padding and gap between sections.   |
| `interactive` | `boolean`                                | `false` | Hover and pressed surface feedback. |
| `className`   | `string`                                 | -       | Layout class on the root.           |

Native `div` attributes pass through to the root.

### Card.Header

| Prop        | Type        | Default | Description                            |
| :---------- | :---------- | :------ | :------------------------------------- |
| `children`  | `ReactNode` | -       | Title and optional `Card.Description`. |
| `action`    | `ReactNode` | -       | Trailing control opposite the title.   |
| `className` | `string`    | -       | Layout class on the header.            |

### Card.Title

| Prop        | Type        | Default | Description           |
| :---------- | :---------- | :------ | :-------------------- |
| `children`  | `ReactNode` | -       | Title content (`h3`). |
| `className` | `string`    | -       | Layout class.         |

### Card.Description

| Prop        | Type        | Default | Description                          |
| :---------- | :---------- | :------ | :----------------------------------- |
| `children`  | `ReactNode` | -       | Supporting copy; omitted when empty. |
| `className` | `string`    | -       | Layout class.                        |

### Card.Content

| Prop        | Type        | Default | Description   |
| :---------- | :---------- | :------ | :------------ |
| `children`  | `ReactNode` | -       | Main body.    |
| `className` | `string`    | -       | Layout class. |

### Card.Footer

| Prop        | Type        | Default | Description                     |
| :---------- | :---------- | :------ | :------------------------------ |
| `children`  | `ReactNode` | -       | Action row; omitted when empty. |
| `className` | `string`    | -       | Layout class.                   |

## Accessibility

- `Card.Title` is an `<h3>`. Match it to the page outline, or replace the title node when you need a different heading level.
- Card is a plain `div`. `interactive` only styles hover and press. If the whole card is clickable, wrap it in a link or button, or add `role`, `tabIndex`, and keyboard handlers yourself.
- Prefer footer or header actions over making the card surface the only control.

## RTL and Language

On `lang="dv"` pages, title and body text use the Dhivehi typefaces from the design tokens. In RTL, the header action and footer button row follow `dir`.
