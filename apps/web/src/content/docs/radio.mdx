# Radio

The Radio component supports two sizes and the full state set from the design system: default, hover, pressed, focus, and disabled.

## Import

```tsx
import { Radio, RadioGroup } from '@tradenetcorp/veli-ui/radio';
```

## Usage

<div className="preview p-4 border border-base-subtle rounded-lg bg-surface-raised mb-4">
  <RadioUsageDemo client:visible />
</div>

```tsx
<RadioGroup defaultValue="a">
  <Radio value="a">Option A</Radio>
  <Radio value="b">Option B</Radio>
  <Radio value="c">Option C</Radio>
</RadioGroup>
```

## Props

### `Radio`

| Prop         | Type           | Default | Description                                                         |
| :----------- | :------------- | :------ | :------------------------------------------------------------------ |
| `size`       | `'md' \| 'lg'` | `'md'`  | Visual size of the radio control.                                   |
| `isDisabled` | `boolean`      | `false` | Disables interaction and applies disabled styling.                  |
| `value`      | `string`       | -       | Value used by the parent `RadioGroup` for selection.                |
| `children`   | `ReactNode`    | -       | Label content.                                                      |
| `className`  | `string`       | -       | Layout-only class override merged onto the outermost radio element. |

### `RadioGroup`

| Prop           | Type                      | Default | Description                                                               |
| :------------- | :------------------------ | :------ | :------------------------------------------------------------------------ |
| `defaultValue` | `string`                  | -       | Uncontrolled initial selected value.                                      |
| `value`        | `string`                  | -       | Controlled selected value.                                                |
| `onChange`     | `(value: string) => void` | -       | Callback when selection changes.                                          |
| `isDisabled`   | `boolean`                 | `false` | Disables all radios in the group.                                         |
| `className`    | `string`                  | -       | Layout-only class override merged onto the outermost radio group element. |

_Note: All other `react-aria-components` Radio and RadioGroup props are supported, excluding `style` overrides._

`className` is a root-level escape hatch for layout and composition cases such as margin and grid or flex placement. The radio control and indicator internals remain private to preserve focus, contrast, disabled, and selected states.
