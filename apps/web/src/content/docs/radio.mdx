# Radio

Use `RadioGroup` when exactly one option may be selected. Selection, keyboard navigation, form values, and validation belong to the group. Use [Checkbox](/docs/checkbox/) for independent choices.

## Import

```tsx
import { Radio, RadioGroup } from '@tradenetcorp/veli-ui/radio';
import { FieldLabel, FieldDescription, FieldError } from '@tradenetcorp/veli-ui/field';
```

## Usage

Place a `FieldLabel` inside the group, or provide `aria-label` or `aria-labelledby`.

<div className="preview mb-4 rounded-lg border p-4">
  <RadioUsageDemo client:load />
</div>

```tsx
<RadioGroup name="contact" defaultValue="email">
  <FieldLabel>Contact method</FieldLabel>
  <Radio value="email">Email</Radio>
  <Radio value="sms">SMS</Radio>
</RadioGroup>
```

## Sizes

`md` has a 16px control and 8px selected indicator. `lg` has a 24px control and 14px indicator. `xl` keeps the 24px control and 14px indicator, with body-lg labels and body-md helper/error text. The label and helper text wrap while the control keeps its size.

<div className="preview mb-4 rounded-lg border p-4">
  <RadioSizesDemo client:load />
</div>

```tsx
<RadioGroup aria-label="Choices" defaultValue="one">
  <Radio size="md" value="one">
    Medium
  </Radio>
  <Radio size="lg" value="two">
    Large
  </Radio>
  <Radio size="xl" value="three">
    Extra large
  </Radio>
</RadioGroup>
```

## Descriptions and validation

Use group `description` and `errorMessage` for shared guidance. When the group is invalid, its error replaces the description. Alternatively, compose `FieldDescription` and `FieldError` inside the group; choose one message approach per slot.

An option's `description` and `errorMessage` are associated with that option. Its `isInvalid` controls local error visibility; group `isInvalid`, `isRequired`, and `validate` control validation.

<div className="preview mb-4 rounded-lg border p-4">
  <RadioMessagesDemo client:load />
</div>

```tsx
<RadioGroup isInvalid errorMessage="Choose a contact method.">
  <FieldLabel>Contact method</FieldLabel>
  <Radio value="email" description="Receive a message in your inbox.">
    Email
  </Radio>
  <Radio value="sms">SMS</Radio>
</RadioGroup>
```

For required forms, set `name` and `isRequired` on the group. `validationBehavior="native"` blocks invalid submission; `"aria"` exposes validation without blocking it. A native reset restores an uncontrolled group's `defaultValue`; reset controlled state in the application.

```tsx
<RadioGroup value={value} onChange={setValue} aria-label="Contact method">

```

## Disabled and read only

`isDisabled` prevents focus and selection and excludes the control from form submission. Group `isReadOnly` keeps its value and allows focus while preventing changes. Individual radios may also be disabled.

## API Reference

Radio and RadioGroup are Veli components on React Aria's [radio components](https://react-spectrum.adobe.com/react-aria/RadioGroup.html), which manage native `<input type="radio">` elements. Props below follow that stack.

### Radio

Veli-specific props for an option inside RadioGroup.

| Prop           | Type                    | Default | Description                                                   |
| :------------- | :---------------------- | :------ | :------------------------------------------------------------ |
| `size`         | `'md' \| 'lg' \| 'xl'`  | `'md'`  | Control and label size.                                       |
| `children`     | `ReactNode`             | -       | Visible option label.                                         |
| `description`  | `ReactNode`             | -       | Helper text associated with this option.                      |
| `errorMessage` | `ReactNode`             | -       | Local error shown when option `isInvalid` is true.            |
| `isInvalid`    | `boolean`               | `false` | Shows the option's local error; group validation is separate. |
| `className`    | `string`                | -       | Layout classes on the root label.                             |
| `ref`          | `Ref<HTMLLabelElement>` | -       | Forwarded to the root label.                                  |

### RadioGroup

Veli-specific props for the composed group.

| Prop           | Type                  | Default | Description                                               |
| :------------- | :-------------------- | :------ | :-------------------------------------------------------- |
| `description`  | `ReactNode`           | -       | Shared helper text.                                       |
| `errorMessage` | `ReactNode`           | -       | Shared error text; replaces the description when invalid. |
| `className`    | `string`              | -       | Layout classes on the root group.                         |
| `ref`          | `Ref<HTMLDivElement>` | -       | Forwarded to the root group.                              |

### React Aria Radio

React Aria's headless option props pass through. Its documentation covers the remaining accessible-label, focus, hover, and DOM props, except the exclusions below.

| Prop         | Type                                  | Default | Description                              |
| :----------- | :------------------------------------ | :------ | :--------------------------------------- |
| `value`      | `string`                              | -       | Required unique value inside RadioGroup. |
| `isDisabled` | `boolean`                             | `false` | Disables this option.                    |
| `autoFocus`  | `boolean`                             | `false` | Focuses this option on mount.            |
| `inputRef`   | `RefObject<HTMLInputElement \| null>` | -       | Ref for the native radio input.          |

### React Aria RadioGroup

React Aria's headless group props pass through. Selection, form values, and validation belong to the group.

| Prop                 | Type                           | Default      | Description                                               |
| :------------------- | :----------------------------- | :----------- | :-------------------------------------------------------- |
| `children`           | `ReactNode` or render function | -            | Options and fields; render functions receive group state. |
| `value`              | `string \| null`               | -            | Controlled selection.                                     |
| `defaultValue`       | `string \| null`               | -            | Uncontrolled initial selection.                           |
| `onChange`           | `(value: string) => void`      | -            | Called when selection changes.                            |
| `isDisabled`         | `boolean`                      | `false`      | Disables all options.                                     |
| `isReadOnly`         | `boolean`                      | `false`      | Allows focus while preventing selection changes.          |
| `isRequired`         | `boolean`                      | `false`      | Requires a selection.                                     |
| `isInvalid`          | `boolean`                      | `false`      | Marks the group invalid.                                  |
| `name`               | `string`                       | -            | Native form field name.                                   |
| `form`               | `string`                       | -            | ID of the owning form.                                    |
| `validate`           | `function`                     | -            | Custom validation of the selected value.                  |
| `validationBehavior` | `'native' \| 'aria'`           | `'native'`   | Native blocking or ARIA validation.                       |
| `orientation`        | `'vertical' \| 'horizontal'`   | `'vertical'` | Announced orientation; use classes for row layout.        |

Not forwarded from React Aria:

| Prop                      | Why                                                              |
| :------------------------ | :--------------------------------------------------------------- |
| `style`                   | Not supported on Radio or RadioGroup.                            |
| `className`               | Replaced by Veli's string layout `className` on the root.        |
| Radio `children`          | Veli owns the control; children provide the visible label.       |
| RadioGroup `label`        | Compose FieldLabel, or use `aria-label` / `aria-labelledby`.     |
| RadioGroup `errorMessage` | Replaced by Veli's message content; functions are not supported. |

### Native radio input

React Aria manages the native input's checked state and keyboard behavior. The option's `value` and the group's `name` and `form` reach that input; `inputRef` accesses it. Set selection through RadioGroup rather than adding a separate `checked` prop to Radio. Internal control and indicator slots remain private.

## Accessibility

Give each option visible label content or `aria-label`/`aria-labelledby`. Tab enters the selected option; arrow keys move selection, skipping disabled options, and Space selects the focused option. Helper and error text describe the input without becoming its name. The focus ring is visible for keyboard use and selection remains visible in forced colors.

Hover colors update immediately. Press and release animate the border and selected indicator over the fast motion token (80ms). Reduced motion disables those transitions.

## RTL and Language

Use the same locale and direction as the surrounding UI. Dhivehi typography follows `lang="dv"`; the label stays beside its control in RTL. Wrap a localized subtree in React Aria's `I18nProvider` when it differs from the application locale so horizontal arrow keys follow that direction.
