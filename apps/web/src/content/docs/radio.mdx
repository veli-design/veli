# Radio

The Radio component supports two sizes and the full state set from the design system: default, hover, pressed, focus, and disabled.

## Import

```tsx
import { Radio, RadioGroup } from '@tradenetcorp/coral-ui/radio';
```

## Usage

<div className="preview p-4 border rounded-lg bg-surface-100 mb-4">

    <Radio value="a">Option A</Radio>
    <Radio value="b">Option B</Radio>
    <Radio value="c">Option C</Radio>
  </RadioGroup>
</div>

## Props

### `Radio`

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `size` | `'sm' \| 'md'` | `'sm'` | Visual size of the radio control. |
| `isDisabled` | `boolean` | `false` | Disables interaction and applies disabled styling. |
| `value` | `string` | - | Value used by the parent `RadioGroup` for selection. |
| `children` | `ReactNode` | - | Label content. |

### `RadioGroup`

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `defaultValue` | `string` | - | Uncontrolled initial selected value. |
| `value` | `string` | - | Controlled selected value. |
| `onChange` | `(value: string) => void` | - | Callback when selection changes. |
| `isDisabled` | `boolean` | `false` | Disables all radios in the group. |

*Note: All other `react-aria-components` Radio and RadioGroup props are supported, excluding `className` and `style` overrides.*
