## Typeface roles

Inter supports Latin interface text. Veli's tokenized Dhivehi stacks provide appropriate Thaana rendering without requiring each service to rebuild its typography rules.

Use the shared sans token for interface text and the mono token only for code, identifiers, or fixed-width technical content.

## Build a clear hierarchy

- Use page titles to orient people, not to repeat navigation labels.
- Keep body text at a comfortable line length and line height.
- Prefer weight and spacing over many different font sizes.
- Use sentence case for headings, labels, and actions.

## Write for scanning

Lead with the information needed to make a decision. Break long guidance into descriptive headings and short paragraphs, and keep labels consistent across related tasks.

Avoid all caps for long text. It reduces word-shape recognition and can create awkward results across scripts.

## Test both scripts

Review real English and Dhivehi content at narrow and wide widths. Check glyph clarity, line height, wrapping, alignment, and truncation rather than assuming the Latin layout will transfer unchanged.
