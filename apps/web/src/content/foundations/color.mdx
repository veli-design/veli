## Use semantic roles

Choose tokens for their purpose rather than their raw hue. Semantic roles preserve meaning when a surface changes theme or the palette evolves.

| Role    | Use                                              |
| :------ | :----------------------------------------------- |
| Base    | Text, borders, and neutral surfaces              |
| Primary | Key actions, links, and selected states          |
| Success | Confirmed or completed outcomes                  |
| Warning | Conditions that need attention                   |
| Danger  | Errors, destructive actions, and critical states |

The samples use `--color-slate-200`, `--color-blue-800`, `--color-success-800`, `--color-orange-800`, and `--color-red-800`.

## Preserve contrast

Text and meaningful graphics must remain readable against their surface. Check the final token combination in every supported theme and interaction state.

Do not rely on color alone to communicate status. Pair it with a label, icon, or structural change that carries the same meaning.

## Support light and dark surfaces

Use semantic variables such as `--color-text-base-default` and `--color-bg-surface-raised`. Avoid binding interface code directly to a numbered palette value unless you are defining a token or controlled illustration.
