# Veli Design licensing scope

“Veli Design” is the primary project name; “Veli” and “Veli Design System” are
alternative names for the same project.

Original project work is copyright © 2026 Government of the Republic of Maldives.
Developed by MINDCo.
Third-party material retains its own rights and permission requirements; the
original-work grants below do not replace them.

## Software: MIT

Original Veli Design software is covered by the MIT licence in `LICENSE`: the
Veli Design React component library, Veli Design tokens and generated CSS/JSON,
the Veli Design CLI, application source, build scripts, configuration, tests and
executable code examples. This includes
code snippets in Markdown/MDX, recipes, stories and tutorial code. CC BY 4.0 is
not applied to software. The copyright line is `2026 Government of the Republic of Maldives`.

## Non-software documentation: CC BY 4.0

Original non-software documentation is covered by Creative Commons Attribution
4.0 International, whose complete standard text is in
`LICENSES/CC-BY-4.0.txt`. This includes original prose in READMEs, guides,
changelogs, agent guidance, Markdown/MDX pages and Storybook explanations.
Original illustrative works created for Veli Design are licensed under CC BY 4.0,
subject to the exclusions below.
Animation implementation, shader code and executable examples remain MIT.
Unclassified or third-party artwork is not automatically included. Code examples embedded in those documents remain MIT.

This map applies by content type, not filename alone: an MDX file may contain
CC BY prose and MIT code. Generated documentation retains the source material's
licence. Imported quotations, third-party notices, official imagery and other
excluded materials do not become CC BY merely by appearing in documentation.
A screenshot is not automatically cleared: the rights in every depicted asset
must be checked. Machine-readable package metadata uses `(MIT AND CC-BY-4.0)`
for mixed software/documentation workspaces; software-only fixtures retain MIT.
This means the respective terms apply to their respective contents, not that
users may choose either licence for every file.

## Excluded material and other rights

The original-work grants do not apply to Veli Design names/logos,
Government of Maldives names, flags, emblems, seals, ministry marks, official
identity elements, designated photographs/illustrations/marketing assets, or
third-party fonts, icons, images, datasets and embedded media. Their appearance
in this repository or a website is not a licence to reuse them. See
`BRAND_POLICY.md`, the `ASSET_LICENSES.md` asset policy and
`THIRD_PARTY_NOTICES.md`. Third-party licence texts remain under their own terms;
the standard CC licence text itself carries Creative Commons' CC0 dedication.

No copyright grant here clears trademark, endorsement, privacy, publicity or
other rights outside its scope. Exclusion does not grant redistribution rights.
Public artefacts containing unverified assets remain blocked until rights are
verified or an explicit removal/replacement is agreed.

## Distributed packages and repository access

Distributed packages include the complete MIT licence and copyright notice,
the complete CC BY 4.0 text for original non-software documentation, and
applicable third-party notices.

Package notices identify the software and documentation licensing scopes,
attribution information and exclusions without requiring access to repository
policy links. No app font, brand image or Block SVG is included; registry and
hosted examples are separate.

The repository currently remains private at `tradenetcorp/veli`; repository and
issue links require access. Public npm publication, repository transfer and
public site/registry deployment require separate rollout approvals. Website-only
font/brand permissions are not evidence about the asset-free npm tarballs;
completed distributed notices and attribution remain npm prerequisites.
