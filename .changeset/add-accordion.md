Add Accordion component built on React Aria `DisclosureGroup`, exported from `@tradenetcorp/veli-ui/accordion`. Support compound composition (`AccordionItem`, `AccordionHeader`, `AccordionPanel`) and a data-driven `items` prop, with `size` (`md`, `lg`), `alignment` (`left`, `right`), and `flushed` variants, skeleton loading via `isSkeleton`, and dedicated accordion design tokens for hover, pressed, and focus states.
